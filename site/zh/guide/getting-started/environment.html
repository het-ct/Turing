安装编译工具链

解压项目配套工具链到不含空格和中文字符的固定目录，将其 bin 目录加入系统 PATH， 重新打开 PowerShell 后验证编译器和 make。工具链名称和版本必须以 SDK 交付说明为准。

安装串口驱动与助手

  1. 根据开发板上的 USB 转串口芯片安装匹配驱动。

  2. 在设备管理器记录 COM 口，插拔设备确认端口会同步出现和消失。

  3. 使用 PlatformIO Serial Monitor 或团队指定串口助手打开端口。

  4. 波特率、数据位、停止位和流控以工程 config.h 及板卡说明为准。

具体驱动型号、默认串口参数和官方下载地址 待开发。

安装 VS Code 与插件

从 VS Code 官方网站安装稳定版。个人电脑可使用 User Installer，共享开发机建议使用 System Installer。随后安装 PlatformIO IDE；HeT Plugin 使用团队提供的离线 .vsix 包安装。

code --install-extension .\het-plugin.vsix

首次构建

cd .\projects\watch320
python gen-srclist.py
make

构建成功后检查 Output/bin/app.dcf 的时间戳。gen-srclist.py 会生成 inclist.mk 等 清单，功能开关由工程配置和 X1 工具箱维护。

编译完成后下载和调试

环境安装只负责准备工具；实际编译、固件下载、串口日志、升级和真机验证见 编译、下载与调试。完成本页命令后直接进入该页执行下载，不要把串口助手当成烧录器使用。

常见问题

  • 命令找不到：重新打开终端并检查 PATH，不要只在旧终端中重试。

  • Python 脚本失败：确认 Python 版本和当前目录，保留第一条异常信息。

  • 串口打不开：关闭其他串口工具，重新插拔并核对 COM 口。

  • 构建成功但无固件：检查第一条编译错误以及 Output/bin 是否被安全软件隔离。
