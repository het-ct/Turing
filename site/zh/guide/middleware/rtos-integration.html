RTOS 与任务模型

当前工程示例以任务、定时器、中断和事件回调组合业务功能，但仓库尚未提供独立、稳定的通用 RTOS 适配文档。不同项目可能使用不同调度器、锁和内存策略，不能直接套用 Linux 线程或 Android Handler 模型。

建议约束

  • 中断只完成采样、清状态和投递事件，耗时计算放到任务或 CBB 工作队列。

  • 明确每个 HAL/CBB API 的调用上下文：初始化任务、普通任务、中断或回调。

  • 对 DMA 缓冲区标注所有权、生命周期、缓存一致性和对齐要求。

  • 看门狗、低功耗和异常恢复由产品应用统一编排。
