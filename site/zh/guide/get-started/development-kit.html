开发套件与首次上电

X1 核心板用于先验证软件、显示、音频、传感器和通信能力，再进入产品板设计。当前说明书给出 S1 核心板的主要接口与管脚信息；S2、S3 的完整配置资料仍待补齐。

准备清单

  • 与工程配置匹配的 X1 核心板、底板和显示模组。

  • 稳定电源、USB/串口线、调试串口工具和目标固件。

  • 已安装的编译工具链、Python 3 与 make，参见 环境安装与工程编译。

  • 板卡版本、芯片封装、LCD/CTP 型号和串口实例记录。

首次上电

  1. 断电检查电源极性、跳帽、排线方向和显示/触摸接口电压。

  2. 仅连接调试串口和供电，上电后确认无异常发热或过流。

  3. 打开串口终端，记录复位原因、固件版本和板型；当前串口参数以目标工程配置为准。

  4. 编译 projects/watch320，确认生成 Output/bin/app.dcf。

  5. 烧录后依次验证启动日志、显示、触摸、音频和产品所需外设。

警告

S1/S2/S3 的管脚和板载器件可能不同。工程中的管脚复用、屏参和电源控制必须与实物版本一致， 不要直接复用另一块板的配置。

当前资料边界

  • S1 管脚与封装概览见 封装与开发板。

  • 电源和板级检查见 电气特性与设计边界 与 标准电路与评审清单。

  • 串口加密烧录工具、连接参数和故障恢复流程：待开发。

  • S2/S3 完整原理图、管脚表和可直接编译的板级工程：待开发。
