GUI 设计工具

GUI 工具用于创建页面、配置控件、绑定 CBB 事件并生成资源。当前仓库的可验证能力以 platform/docs/pages/gui、platform/middlewares/gui 和项目实际配置为准。

工作流

  1. 确认目标屏幕分辨率、像素格式、输入设备和内存预算。

  2. 在页面层创建控件，统一设置几何、样式、可见性和事件回调。

  3. 将业务动作绑定到 CBB/应用事件，不在控件回调中直接操作寄存器或阻塞等待。

  4. 导出图片、字体和布局资源，检查资源大小、路径和编码。

  5. 在目标板上验证首帧、刷新率、触摸、旋钮、低功耗唤醒和异常页面。

当前控件入口

  • 基础显示：Label、Image、Bar、LED。

  • 交互控件：Button、Checkbox、Slider、Switch、Roller、Textarea。

  • 布局与物理：Flex、Grid、页面事件和输入设备适配。

控件 API 与示例见 UI 组件；品类页面和状态机见 咖啡机平台方案。

设计检查

  • 页面切换不泄漏控件、定时器、动画或图片缓冲区。

  • 文本、图片和字体资源均有明确的 Flash/RAM 归属。

  • 高频刷新区域使用合适的 .com/.bank 放置和 DMA 策略。

  • 业务状态与控件显示分离，异常时 UI 不得绕过硬件安全联锁。
