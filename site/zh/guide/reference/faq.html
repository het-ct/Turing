FAQ

编译器或 make 找不到

在新终端运行工具链版本命令、make --version 和 python --version。检查 PATH 后重新 打开终端，详细步骤见 环境搭建。

编译成功但没有 app.dcf

确认位于目标工程目录并检查第一条编译错误。正常输出为 projects/<project>/Output/bin/app.dcf。重新执行 python gen-srclist.py，核对功能开关和 inclist.mk。

下载器找不到串口

关闭串口助手，重新插拔开发板，在设备管理器确认驱动和 COM 口。具体驱动型号和下载参数 待开发。

外设初始化失败

记录返回值、外设实例、管脚复用、时钟、电源、地址和初始化顺序。先运行 示例 中的最小示例，再接入 BSP 和业务。

显示正常但触摸无响应

分别验证触摸电源、复位、中断、IIC 地址和原始坐标，确认显示与触摸没有复用冲突；屏幕旋转后 同步检查坐标转换。

升级后无法启动

保留升级日志，核对目标分区、固件完整性、签名、板卡版本和镜像确认状态。停止重复覆盖可启动 分区，按 OTA 升级 的异常路径恢复。量产强制恢复流程 待开发。
