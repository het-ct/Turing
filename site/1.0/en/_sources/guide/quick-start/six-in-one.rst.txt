六合一开发套件
==============

开发板概述
----------

六合一开发套件以 Het-X1 核心板为控制核心，用于集中验证显示与触摸、音频输入输出、摄像头、
蓝牙/Wi-Fi、传感器及常用控制外设。套件适合评估芯片能力、运行 HAL 示例以及建立产品板配置，
不应直接替代量产硬件的电气和可靠性验证。

.. image:: /_static/img/六合一实物渲染.png
   :alt: Het-X1 六合一开发套件实物
   :class: manual-figure
   :align: center

上电前确认核心板型号、底板版本、显示和触摸模组、电源输入、调试串口及跳帽位置。S1 核心板
接口资料见 :doc:`../platform/packages-boards`；S2、S3 完整套件资料 **待开发**。

.. image:: /_static/img/六合一开发板PCB.png

源码或固件获取
--------------

当前仓库已包含 SDK 源码、``projects/watch320``、``projects/haier_hmi`` 和外设示例。
交付包应至少包含：

* ``platform``：HAL、BSP、中间件、服务和示例。
* ``projects``：可编译的产品或演示工程。
* 编译工具链、烧录工具、板卡资料、版本记录和已知问题。
* 已构建固件 ``Output/bin/app.dcf`` 及其适用板卡说明。

正式下载地址、历史版本归档和校验清单 **待开发**，当前应从项目负责人提供的受控交付包获取。

环境搭建
--------

安装编译链、Python、VS Code、串口驱动和插件，参见 :doc:`../getting-started/environment`。
完成后先编译现有工程：

.. code-block:: powershell

   cd .\projects\watch320
   python gen-srclist.py
   make

固件或程序下载
--------------

1. 确认目标板型、芯片封装和 ``config.h`` 配置一致。
2. 关闭占用下载串口的串口助手，连接开发板并进入下载模式。
3. 在配套 Downloader 中选择 ``Output/bin/app.dcf``，核对端口后开始下载。
4. 复位开发板，重新打开串口终端，核对版本、复位原因和启动日志。
5. 依次验证显示、触摸、音频、摄像头、通信和目标外设。

.. warning::

   下载工具的端口参数、启动脚电平、加密烧录和失败恢复步骤尚无受控公开说明，**待开发**。
   在量产流程发布前，不要自行修改安全配置或擦除未知分区。
