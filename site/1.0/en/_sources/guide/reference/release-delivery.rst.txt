版本、下载与交付物
==================

Het-X1 SDK 交付应把源码、工具、硬件资料和版本记录作为同一套受控基线。不要只发送一个固件文件，
否则接收方无法确认工具链、板卡和资源版本是否匹配。

建议交付内容
------------

.. list-table:: MCU SDK 交付清单
   :header-rows: 1
   :widths: 24 42 34

   * - 类别
     - 内容
     - 验证方法
   * - SDK 源码
     - ``platform``、目标 ``projects``、构建脚本和依赖声明
     - 从干净目录完成一次全量编译
   * - 固件
     - ``app.dcf``、校验值、版本号和适用板型
     - 烧录后核对启动日志与功能冒烟测试
   * - 工具
     - 编译链、烧录器、X1 工具箱及版本说明
     - 记录工具版本并验证命令可执行
   * - 硬件资料
     - 原理图、PCB 约束、BOM/AVL、封装与板卡版本
     - 与实物丝印和工程配置交叉核对
   * - 文档
     - 本站离线包、API、变更记录和已知问题
     - 解压后从 ``index.html`` 检查中英文链接

版本规则
--------

发布记录至少包含 SDK 版本、Git 提交、构建日期、工具链版本、支持板卡、已知限制和升级兼容性。
固件、资源和配置分别变化时，应明确它们的兼容关系。文档版本由 ``metadata.json`` 的
``doc_versions`` 管理，构建方式见项目的文档发布说明。
