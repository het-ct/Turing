版本规则
========

版本组成
--------

SDK 发布版本建议采用 ``主版本.次版本.修订号``：

* 主版本：存在不兼容 API、配置、分区或工具变化。
* 次版本：向后兼容的新功能或新硬件支持。
* 修订号：兼容性问题修复和文档修订。

发布记录
--------

每个版本至少记录 SDK 版本、Git 提交、构建时间、工具链、支持板卡、固件/资源格式、API 变化、
升级路径、已知问题和验证结论。文档版本由 ``metadata.json`` 的 ``doc_versions`` 管理。

兼容性
------

芯片封装、核心板、显示/触摸、固件、UI 资源、配置和升级器分别具有版本，发布说明必须给出兼容
矩阵。废弃 API 先标记并给出替代方案，再在主版本中删除。稳定的生命周期和长期支持策略
**待开发**。
