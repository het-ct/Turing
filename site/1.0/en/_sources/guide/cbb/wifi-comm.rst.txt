WIFI 通讯库
===========

.. container:: module-summary cbb-summary

   **CBB 能力组件**

   对应 TCP、UDP、MQTT、WebSocket、OPC UA、HTTPS、Matter 等网络协议能力。

概述
----

本模块面向 **Wi-Fi 网络通信**。该页面建议补充协议栈封装、连接状态机、重连策略、安全认证与典型使用案例。

核心能力
--------

.. container:: capability-list

   * **基础协议**：说明 TCP、UDP、HTTPS、WebSocket 的封装能力。
   * **IoT 协议**：说明 MQTT、OPC UA、Matter 等物联网能力。
   * **网络稳态**：说明连接保持、异常恢复和安全认证机制。

使用方法
--------

初始化网络设备，注册连接事件，完成入网、地址获取、重连和上层数据通道管理。

#. 准备依赖的 HAL、板级资源和任务/中断上下文。
#. 创建配置并注册状态、数据或错误回调。
#. 启动组件，将输入数据或系统事件送入处理接口。
#. 在业务循环中消费输出，并处理超时、断连和资源不足。
#. 停止数据源，等待异步操作结束，再释放组件资源。

使用示例
--------

以下代码展示应用适配层的接入骨架。函数名用于说明职责，应替换为项目中实际提供的 CBB 接口。

.. code-block:: c

   static void app_wifi_event(const void *event)
   {
       /* 将状态或处理结果投递到产品业务层。 */
       (void)event;
   }

   int app_wifi_start(void)
   {
       int ret = board_wifi_prepare();
       if (ret != 0) return ret;

       ret = product_wifi_init(app_wifi_event);
       if (ret != 0) return ret;
       return product_wifi_start();
   }

   int app_wifi_process(const void *network_event)
   {
       if (network_event == NULL) return -1;
       return product_wifi_process(network_event);
   }

API 说明
--------

当前 CBB 页面尚未关联稳定的公开头文件。建议由具体实现提供以下适配层职责，并在公开头文件落地后改为 Doxygen 自动接口说明。

.. list-table:: 建议适配层接口
   :header-rows: 1
   :widths: 28 45 27

   * - 接口职责
     - 说明
     - 调用约束
   * - ``init(config, callback)``
     - 校验配置、创建上下文并注册事件回调。
     - 每个实例只初始化一次。
   * - ``start()``
     - 启动数据源、协议状态机或算法任务。
     - 必须在初始化成功后调用。
   * - ``process(input)``
     - 输入数据帧或系统事件并产生结果。
     - 明确线程、中断和缓冲区所有权。
   * - ``set_callback(callback)``
     - 注册状态、数据和错误通知。
     - 回调中避免阻塞操作。
   * - ``stop() / deinit()``
     - 停止异步来源并释放资源。
     - 先停止，再销毁上下文。

注意事项
--------

* 对实时数据链路明确采样周期、最大延迟和缓冲深度。
* 错误码应保留底层原因，并由产品层决定重试、降级或复位策略。
* 回调、DMA 和任务仍在运行时，不得释放配置、缓冲区或用户上下文。
* CBB 与 HAL 的依赖关系应集中在适配层，避免业务代码直接访问芯片实现。
