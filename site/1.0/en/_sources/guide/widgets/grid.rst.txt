het_grid 网格布局容器

include/het_grid.h

组件说明
--------

het_grid 是二维网格布局容器，通过列行模板将子项放置在指定单元，并支持跨列/跨行。

* 适用于仪表盘、菜单矩阵、信息面板等规则网格场景。

* 先定义模板（列数/行数），再将控件绑定到单元坐标。

* 可通过跨行跨列构建不等尺寸区域。

     - 值
     - 说明
   * - HET_GRID_MAX_ITEMS
     - 4（可重定义）
     - 容器可容纳的最大子项数量。
   * - HET_GRID_MAX_TRACKS
     - 15
     - 行/列轨道最大数量上限。

使用示例
--------

.. code-block:: c

   void *grid = het_grid_create(frm);
   het_grid_set_geometry(grid, HET_GEOMETRY(160, 120, 220, 160));
   het_grid_set_padding(grid, HET_PADDING(8, 8, 8, 8));
   het_grid_set_gap(grid, 6, 6);
   het_grid_set_template(grid, 3, 2);
   
   void *icon = het_image_create(frm, HET_BG_MODE_2D);
   void *name = het_label_create(frm, NULL, 32);
   void *value = het_label_create(frm, NULL, 16);
   
   het_grid_add(grid, icon, 0, 0, 1, 2);      // 左侧图标跨两行
   het_grid_add_cell(grid, name, 1, 0);       // 标题
   het_grid_add(grid, value, 1, 1, 2, 1);     // 数值横跨两列
   
   het_grid_update(grid);
