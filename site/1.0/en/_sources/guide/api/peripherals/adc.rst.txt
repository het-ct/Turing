ADC 模数转换（het_adc.h）
=========================

源文件：``platform/hal/api/het_adc.h``

概述
----

Het-X1 集成 10 位、16 通道 SAR ADC，可用于电池电压、按键和温度等模拟量采集，并支持 DMA 数据传输。

用法
----

使用默认句柄打开 ADC，按需使能通道并读取采样值；退出前关闭通道。通道和引脚由板级配置确定。

典型流程
--------

#. 获取默认配置或准备板级配置。
#. 初始化外设并检查返回值。
#. 执行读写、控制或回调注册操作。
#. 停止异步来源并反初始化外设。

示例
----

.. code-block:: c

   #include "het_adc.h"

   int adc_read_once(uint16_t *sample)
   {
       het_adc_handle_t adc = het_adc_def_cfg();
       int ret = het_adc_open(&adc);
       if (ret != HET_OK) return ret;
       ret = het_adc_enable(&adc, 1);
       if (ret == HET_OK) ret = het_adc_read(&adc, sample);
       het_adc_enable(&adc, 0);
       het_adc_close(&adc);
       return ret;
   }
