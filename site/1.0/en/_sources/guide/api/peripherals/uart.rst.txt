UART 异步串口（het_uart.h）
===========================

源文件：``platform/hal/api/het_uart.h``

概述
----

Het-X1 的 UART0/1 支持通用异步通信、灵活 GPIO 映射和 Key Match；芯片还提供带 CTS/RTS、DMA 和循环缓冲能力的高速 HSUART。

用法
----

由板级配置设置实例、引脚和波特率。初始化后调用读写接口；异步接收先注册回调，关闭串口前注销回调并反初始化。

典型流程
--------

#. 获取默认配置或准备板级配置。
#. 初始化外设并检查返回值。
#. 执行读写、控制或回调注册操作。
#. 停止异步来源并反初始化外设。

示例
----

.. code-block:: c

   #include "het_uart.h"

   int uart_send(het_uart_id_t id, const uint8_t *data, uint16_t len)
   {
       het_uart_handle_t uart = het_uart_def_cfg();
       int ret = het_uart_init(&uart);
       if (ret != HET_OK) return ret;
       ret = het_uart_write(id, data, len);
       het_uart_deinit(id);
       return ret;
   }
