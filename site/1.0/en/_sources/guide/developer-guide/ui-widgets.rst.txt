UI 控件
=======

概述
----

Het-X1 UI 组件位于 ``platform/middlewares/gui/components``，产品页面和菜单位于
``platform/services/UI/form``。控件文档包含创建、布局、样式、事件和销毁流程。

控件目录
--------

Label、Button、Slider、Bar、Arc、Image、Checkbox、Switch、Roller、Textarea、Flex 和 Grid
均已有页面，入口见 :doc:`../widgets/index`。页面内容直接依据 ``platform/docs/pages/gui/*.js``
中对应控件的创建、参数、事件和示例整理；RadioBox、Video、二维码等说明书规划控件尚缺稳定
实现的完整页面，**待开发**。

使用方法
--------

创建父对象后初始化控件，设置尺寸和样式，注册事件回调，再加入页面生命周期。页面退出时先停止
动画和定时器，再销毁子对象和资源。

示例
----

.. code-block:: c

   het_button_t *button = het_button_create(parent);
   het_button_set_text(button, "Start");
   het_button_set_event_cb(button, on_start_clicked, NULL);

   /* 页面销毁前停止回调来源，再释放对象。 */
   het_button_destroy(button);

注意事项
--------

* 事件回调不得长期阻塞刷新任务。
* 图片和字体资源应校验地址、大小和生命周期。
* 控件尺寸、触摸坐标和屏幕旋转必须同步配置。

主要 API
--------

控件 API 见 :doc:`../api/ui`；各控件的参数、返回值、事件过滤和代码示例见
:doc:`../widgets/index` 下对应页面。
