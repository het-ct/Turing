Component Description

het_led provides an LVGL style circular status indicator that supports color, brightness, switch, flip, blink and click callbacks.

Parameters and options

Listen for messages

filter conditions

result

MSG_CTP_CLICK

Contact hit LED circular area (center hit judgment)

Hit: Trigger callback and consume the message; Miss: Transparently transmit the message

API introduction

void *het_led_create(compo_form_t *frm)

Create an LED component, which is green by default and at off brightness.

Parameters: frm target form.

Returns: void* LED component handle, returns NULL on failure.

void het_led_set_geometry(void *obj, const rect_t rect)

Set geometry properties.

Parameters: obj LED handle; rect geometry information.

void het_led_set_color(void *obj, const uint8_t r, const uint8_t g, const uint8_t b)

Set RGB888 color.

Parameters: obj LED handle; r/g/b three color channel values.

void het_led_set_brightness(void *obj, const uint8_t brightness)

Set brightness 0~255.

Parameters: obj LED handle; brightness brightness value.

void het_led_on(void *obj) / void het_led_off(void *obj) / void het_led_toggle(void *obj)

On, off, flip state.

Parameters: obj LED handle.

void het_led_set_blink(void *obj, const uint16_t on_ms, const uint16_t off_ms)

Set the flashing rhythm. If any parameter is 0, the flashing will stop.

Parameters: obj LED handle; on_ms is the lighting time; off_ms is the off time, the unit is ms.

void het_led_set_slot(void *obj, event_cb cb, void *user_data)

Register click callback, event code is HET_EVENT_CLICKED.

Parameters: obj LED handle; cb callback function; user_data user transparent transmission pointer.

void het_led_set_visible(void *obj, const bool visible)

Set visibility.

Parameters: obj LED handle; visible whether it is visible.

uint8_t het_led_get_brightness(const void *obj)

Get the current brightness.

Parameters: obj LED handle.

Return: uint8_t current brightness value.

bool het_led_is_on(const void *obj)

Check whether it is on.

Parameters: obj LED handle.

Return: bool If true, it means it is currently on.

Usage example

void *led = het_led_create(frm);
het_led_set_geometry(led, HET_GEOMETRY(220, 70, 24, 24));
het_led_set_color(led, 0, 185, 90);
het_led_on(led);

// 心跳闪烁：亮 120ms，灭 880ms
het_led_set_blink(led, 120, 880);
