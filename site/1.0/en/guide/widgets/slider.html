Component Description

het_slider is based on the het_bar extension and provides draggable knobs for interactive value selection (volume, brightness, progress positioning, etc.).

Parameters and options

Listen for messages

filter conditions

result

MSG_CTP_TOUCH/CLICK/LONG/LONG_*/SHORT_*

The contact hits the slider hit area (the track and knob sizes take the larger range)

Update dragging status

MSG_CTP_MOVE_RT/LT/UP/DN (and default branch)

dragging=true and the current touch point can be obtained

When updatable: consume the message and refresh the value; otherwise: transparently transmit the message

API introduction

void * het_slider_create(compo_form_t *frm)

Create the slider component.

Parameters: frm target form.

Returns: void* slider component handle, returns NULL on failure.

void het_slider_set_geometry(void *obj, const rect_t rect)

Set position and size.

Parameters: obj slider handle; rect geometry information.

void het_slider_set_range(void *obj, const int32_t min, const int32_t max)

Set the value range.

Parameters: obj slider handle; min minimum value; max maximum value.

void het_slider_set_value(void *obj, const int32_t value)

Set the value without triggering the callback.

Parameters: obj slider handle; value target value.

void het_slider_set_value_notify(void *obj, const int32_t value, void *param)

Set the value and trigger the value change event. Param can transparently transmit the business context.

Parameters: obj slider handle; value target value; param callback transparent transmission parameter.

void het_slider_set_knob_size(void *obj, const uint8_t size)

Set the knob size.

Parameters: obj slider handle; size knob size.

void het_slider_set_knob_color(void *obj, const uint16_t color)

Set the knob color (RGB565).

Parameters: obj slider handle; color knob color.

void het_slider_set_color(void *obj, const uint16_t knob_color, const uint16_t indic_color, const uint16_t bg_color)

Set knob, indicator, and track background colors all at once.

Parameters: obj slider handle; knob_color knob color; indic_color passed area color; bg_color track background color.

void het_slider_set_radius(void *obj, const uint16_t radius)

Set track fillets.

Parameters: obj slider handle; radius track fillet radius.

void het_slider_set_indic_padding(void *obj, const het_pad_t padding)

Set the indicator to retract to control the distance between the traveled area and the edge of the track.

Parameters: obj slider handle; padding indicator padding.

void het_slider_set_orientation(void *obj, const het_bar_orientation orientation)

Set horizontal or vertical orientation.

Parameters: obj slider handle; orientation direction enumeration.

void het_slider_set_slot(void *obj, event_cb slot, void *user_data)

Register callback, event code is HET_EVENT_VALUE_CHANGED.

Parameters: obj slider handle; slot callback function; user_data user transparent transmission pointer.

void het_slider_set_visible(void *obj, const bool visible)

Set visibility.

Parameters: obj slider handle; visible whether to display.

Get the current value.

Return: int32_t current value.

Get min/max value.

Usage example

static void on_volume_changed(const het_event_t * const e)
{
    void *slider = e->original;
    int32_t vol = het_slider_get_value(slider);
    (void)vol;
}

void *slider = het_slider_create(frm);
het_slider_set_geometry(slider, HET_GEOMETRY(160, 152, 180, 22));
het_slider_set_range(slider, 0, 100);
het_slider_set_color(slider, COLOR_WHITE, make_color(67, 145, 255), make_color(45, 52, 66));
het_slider_set_knob_size(slider, 18);
het_slider_set_value(slider, 40);
het_slider_set_slot(slider, on_volume_changed, NULL);
