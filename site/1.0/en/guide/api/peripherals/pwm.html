PWM pulse width modulation (het_pwm.h)

Source file: platform/hal/api/het_pwm.h

Overview

Timer3/4 of Het-X1 supports dual-channel PWM, and Timer5 supports up to 6 channels of PWM, which can be used for backlight, buzzer, motor and lighting effect control.

usage

The timer channel and pin are selected by board configuration. After initialization, set the frequency and thousandth duty cycle, and then start the output; check the return value when modifying parameters.

Typical process

  1. Get the default configuration or prepare board-level configuration.

  2. Initialize the peripheral and check the return value.

  3. Perform read, write, control, or callback registration operations.

  4. Stop the asynchronous source and deinitialize the peripheral.

Example

#include "het_pwm.h"

int pwm_start_output(het_pwm_id_t id, uint32_t hz, uint32_t duty_permile)
{
    het_pwm_handle_t pwm = het_pwm_def_cfg();
    int ret = het_pwm_init(&pwm);
    if (ret != HET_OK) return ret;
    if ((ret = het_pwm_set_frequency(id, hz)) != HET_OK) return ret;
    if ((ret = het_pwm_set_duty(id, duty_permile)) != HET_OK) return ret;
    return het_pwm_start(id);
}
