LCD display controller (het_lcd.h)

Source file: platform/hal/api/het_lcd.h

Overview

The Het-X1 LCD controller supports serial/parallel RGB, 8080, DSPI, QSPI and 3/4-wire SPI interfaces, and supports multiple pixel formats and GPU rendering result output.

usage

Initialize the LCD after preparing a driver description that matches the panel, and then configure the brightness, transmission timing, and TE mode. Panel commands and pixel transfers should comply with the data sheet of the specific screen.

Typical process

  1. Get the default configuration or prepare board-level configuration.

  2. Initialize the peripheral and check the return value.

  3. Perform read, write, control, or callback registration operations.

  4. Stop the asynchronous source and deinitialize the peripheral.

Example

#include "het_lcd.h"

int display_start(lcd_drv_t *driver, u8 brightness)
{
    int ret = het_lcd_init(driver);
    if (ret != HET_OK) return ret;
    return het_lcd_set_brightness(brightness);
}

void display_stop(void)
{
    het_lcd_deinit();
}
