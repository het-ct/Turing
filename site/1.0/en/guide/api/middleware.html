const het_camera_dev_t *het_camera_register(het_camera_dev_t *dev, het_interface_t *const bus_if, het_interface_t *const dvp_if, const het_device_model model)

注册一路摄像头的总线接口与 DVP 硬件接口。

每调用一次，在内部设备池（最多 HET_CAMERA_MAX_DEV 路）中分配一个 het_camera_dev_t 并与接口绑定，同时探测并注册匹配的传感器驱动。

幂等性：若用相同 bus_if 再次调用，会覆盖同一设备槽（重新探测驱动）。

Note

多路摄像头共享同一 DVP 控制器时，dvp_if 可传入同一实例。

Parameters:

  • dev – 设备描述符指针，若为 NULL 则从设备池分配新的描述符

  • bus_if – 传感器寄存器总线（I²C/SPI），BSP 实现

  • dvp_if – DVP 硬件接口，BSP 实现，命令语义见 het_type.h HET_DVP_CMD_*

  • model – 传感器型号（由传感器驱动定义），用于探测时验证 ID

Returns:

成功：指向已分配设备描述符的指针；失败（池满或参数非法）：NULL

int het_camera_init(const het_camera_dev_t *const dev)

通过传感器驱动的 init 回调初始化传感器寄存器。

调用 dev->sensor_drv.interface.init(dev)，该回调由传感器驱动 （如 het_sensor_gc032a_register）注入，负责向传感器写入全套寄存器序列。 通常由 BSP 的旧系统 image_sensor_drv_register 代替，两者二选一。

Parameters:

  • dev – 由 het_camera_register() 返回的设备描述符

Returns:

0 成功；负值：驱动返回的错误码

int het_camera_get_sensor_id(const het_camera_dev_t *const dev)

读取传感器 ID（用于自动识别/验证）。

通过 sensor_drv.interface.ctrl(HET_DEV_CMD_GET_SENSOR_ID) 读取芯片 ID。 需先完成 bus_if 初始化（DVP 时钟已使能、I²C 已拉起）。

Note

因为头插关系，总线设备编号与注册时的顺序是相反的。

Parameters:

  • dev – 设备描述符指针

Returns:

≥0：传感器 ID；负值：读取失败（总线未就绪或传感器未响应）

int het_camera_open(const het_camera_dev_t *const dev, het_camera_ctx_t *ctx, const het_camera_cfg_t *cfg)

初始化 DVP 流水线，建立缓冲区映射，启动 DMA 采集。

内部完成以下操作（无需调用方关心细节）：

  1. 计算显示缩放比例（image_size → disp_size）

  2. 建立显示缓冲区：若 cfg->disp_buf 非 NULL，通过 dvp_if BUF_MAP_CPU 转换为 CPU 可访问地址；否则通过 dvp_if BUF_ALLOC 动态分配。

  3. 写入 magic 头（0x24150 + w + h），并 cache flush。

  4. 建立 DMA 缓冲区映射（CPU 地址）。

  5. 发送 HET_DVP_CMD_START，配置 stride/lines 并启动采集。

  6. 若 cfg->full_buf 非 NULL，建立全帧缓冲区和变焦缓冲区。

  7. 初始化 zoom_div = 1，关联 dev_ref，置 is_drv_ready/is_pipeline_init。

Parameters:

  • dev – 由 het_camera_register() 返回的设备描述符，决定使用哪路 dvp_if

  • ctx – BSP 声明的共享上下文（需带正确的链接器节属性）

  • cfg – 流水线运行时参数（代替编译期宏）

Pre:

调用前须已：

  • het_camera_register() 返回有效 dev

  • dev->dvp_if->init(dev) 使能 DVP 时钟

  • 传感器寄存器已初始化（image_sensor_drv_register 或 het_camera_init）

Returns:

0 成功；-1 参数非法或缓冲区分配失败

void het_camera_close(het_camera_ctx_t *ctx)

停止 DVP 流水线，释放动态分配的缓冲区，关闭 DVP 时钟。

内部操作顺序：

  1. 清除 is_drv_ready / is_pipeline_init（立即阻止 GPU 继续产生帧）

  2. 发送 HET_DVP_CMD_STOP（BSP 内含延时，等待 DMA 排空）

  3. 清除 disp_is_ready / frame_ready

  4. 若 disp_alloc == true，通过 dvp_if BUF_FREE 释放显示缓冲区

  5. 清空 disp_buff / dvp_full_buff

  6. 发送 HET_DVP_CMD_CLK_DISABLE 关闭 DVP 时钟

Note

应在 image_sensor_drv_unregister()「之后」调用，确保传感器先停止 输出数据，再停止 DMA，避免出现帧撕裂写入。

Parameters:

  • ctx – 已通过 het_camera_open() 初始化的上下文

uint8_t *het_camera_frame_get(het_camera_ctx_t *ctx)

获取可供显示的帧缓冲区首地址（含 8 字节 magic/size 头）。

校验 magic（0x24150）及宽高非零后，返回 disp_buff - 8 的指针。 调用方在读取帧内容后，负责通知上层渲染。 本函数不清除 frame_ready，调用方根据需要自行管理。

Parameters:

  • ctx – 目标摄像头上下文

Returns:

非 NULL：帧 header 指针（layout: [magic:4][w:2][h:2][data…]）； NULL：disp_buff 为空或 magic 校验失败（数据异常）
