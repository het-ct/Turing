Drivers and BSP

Overview

platform/bsp maps HAL to directly usable onboard device capabilities, including display, touch, camera, audio, sensor, Flash, buttons, charging, USB and network. The driver must isolate device differences and not write product services to the bus layer.

Access process

  1. Verify device power, reset, bus, address, and interrupt connections.

  2. First use HAL to verify bus reading and writing, and then access the device initialization table.

  3. Implement init/read/write/deinit or the interface agreed to by an existing module in the BSP.

  4. Place the device model and pin selection into config.h.

  5. Verify cold starts, warm resets, bus exceptions, low-power recovery and long-term operation.

Existing driver

The display and touch drivers are located at platform/middlewares/gui/tft and platform/middlewares/gui/ctp; the camera adapter is located at platform/bsp/bsp_image_sensor; the sensor driver is located at platform/bsp/bsp_sensor.

Key points for using the driver

  • Display: power on/reset first, then configure the bus and windows, and finally turn on the backlight and refresh.

  • Touch: Confirm the IIC address, INT/RST first, and then process the coordinate direction and screen rotation.

  • Camera: configure the clock, frame format and buffer, and return the DMA buffer in time after the frame processing is completed.

  • Audio: Set the sampling rate, gain and input and output channels, and call the processing function in the playback loop.

  • Sensor: First detect the device ID, then perform calibration and periodic reading, and release the bus when abnormal.

Public het API See the device-specific bsp_* interface of API reference；BSP for reference only as implementation details and are outside the scope of the API reference.

Example

int sensor_probe(void)
{
    /* 先验证总线，再进入器件初始化，避免吞掉 NACK。 */
    int ret = bsp_i2c_init();
    if (ret < 0) return ret;
    return bsp_sensor_init();
}

Main API

BSP has not yet formed a unified public API list. Currently, each bsp_*.h shall prevail; stable public header files, error models and thread safety instructions are to be developed.
