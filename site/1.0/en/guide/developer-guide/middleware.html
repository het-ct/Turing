middleware

Overview

platform/middlewares provides GUI, LittleFS, FlashDB/FAL, protocols, sensors and universal containers decoupled from specific products. The middleware is responsible for the reusability mechanism, and the product strategy is still determined by the service or application layer.

How to use

First configure the underlying storage, bus or display resources, then initialize the middleware and let a single task drive its periodic processing. File systems and databases must define power loss consistency, wear and migration policies; GUIs must explicitly refresh threads and object lifecycles.

Example

int storage_service_init(void)
{
    int ret = het_fs_init();
    if (ret < 0) return ret;
    return app_database_init();
}
