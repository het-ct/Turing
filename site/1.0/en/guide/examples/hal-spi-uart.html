SPI vs. UART Example

SPI

platform/examples/hal/example_spi.c includes synchronous transmission, DMA asynchronous transmission and W25Q series Flash ID reading. The example defaults to SPI1, 4 MHz, and a fixed PB pin set. When switching the target board, SCK, CS, MOSI, MISO, WP, HOLD and chip select valid levels must be modified simultaneously.

UART

platform/examples/hal/example_uart.c uses high-speed UART, PB1/PB0, 1.5 Mbps and DMA receive buffer.

het_uart_handle_t uart = het_uart_def_cfg();
uart.id = HET_UART_ID_H0;
uart.tx_pin = HET_GPIO_PIN_PB1;
uart.rx_pin = HET_GPIO_PIN_PB0;
uart.baud = 1500000;
uart.rx_buf = rx_buffer;
uart.rx_buf_len = sizeof(rx_buffer);
return het_uart_init(&uart);

API see SPI serial peripheral interface (het_spi.h) and UART asynchronous serial port (het_uart.h)。
