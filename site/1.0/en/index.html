Het-X1 SDK Development Manual

This manual is oriented to Het-X1 MCU product development, starting from the development kit, environment installation and engineering construction, and gradually moving into software architecture, board-level adaptation, peripheral API, UI/CBB, hardware design and mass production delivery. The content is based on the current warehouse code and the “Turing Platform User Manual”; chapters that have no stable implementation or data are clearly marked as “to be developed”.
