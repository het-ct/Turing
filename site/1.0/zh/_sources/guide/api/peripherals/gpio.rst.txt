GPIO 通用输入输出（het_gpio.h）
===============================

源文件：``platform/hal/api/het_gpio.h``

概述
----

Het-X1 提供 PA、PB、PE、PF、PG 多组 GPIO，支持输入输出、上下拉、驱动能力、数字/模拟切换、复用映射以及边沿中断和唤醒。

用法
----

GPIO 引脚和模式由板级配置提供。应用获取默认句柄并初始化后，可读写电平或注册中断回调；释放前先关闭中断并注销回调。

典型流程
--------

#. 获取默认配置或准备板级配置。
#. 初始化外设并检查返回值。
#. 执行读写、控制或回调注册操作。
#. 停止异步来源并反初始化外设。

示例
----

.. code-block:: c

   #include "het_gpio.h"

   int gpio_prepare(void)
   {
       het_gpio_handle_t gpio = het_gpio_def_cfg();
       return het_gpio_init(&gpio);
   }
   
   int gpio_set_level(het_gpio_id_t pin, uint8_t level)
   {
       return het_gpio_write(pin, level);
   }
