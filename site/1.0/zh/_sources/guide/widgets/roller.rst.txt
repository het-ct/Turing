组件说明
--------

het_roller 用于在有限候选集中进行上下滚动选择，常见于日期、时间、枚举配置等场景。

物理效果
--------

参数与选项
----------

.. list-table::
   :header-rows: 1

   * - 监听消息
     - 过滤条件
     - 结果
   * - MSG_CTP_TOUCH
     - 触点命中 roller 背景区域
     - 命中：进入拖动并消费消息；未命中：透传消息
   * - MSG_CTP_MOVE\_\*、MSG_CTP_LONG\*、MSG_CTP_SHORT\_\*、MSG_CTP_CLICK、MSG_CTP_LONG_LIFT
     - dragging=true
     - 拖动中更新位移；松手时启动惯性/吸附；消费消息
   * - 其他消息
     - 若仍处于 dragging 也会执行收尾释放
     - 收尾后消费消息，否则透传消息

参数与选项
----------

.. list-table::
   :header-rows: 1

   * - 模式
     - 语义
     - 适用场景
   * - HET_ROLLER_PHYSICS_SNAP
     - 无惯性，松手后直接吸附
     - 严谨配置页
   * - HET_ROLLER_PHYSICS_INERTIA
     - 按速度滑动后再吸附
     - 通用列表滚动
   * - HET_ROLLER_PHYSICS_ELASTIC
     - 惯性 + 边界阻尼/回弹
     - 更自然触感

使用示例
--------

.. code-block:: c

   const het_roller_physics_t p = HET_ROLLER_PHYSICS_CONFIG(
       HET_ROLLER_PHYSICS_INERTIA,
       180,   // snap_ms
       3600,  // decel
       5,     // max_throw_rows
       96     // edge_resist
   );
   het_roller_set_physics(roller, &p);

.. code-block:: c

   static const char *days[] = {"一", "二", "三", "四", "五", "六", "日"};
   
   void *roller = het_roller_create(frm, 5);
   het_roller_set_geometry(roller, HET_GEOMETRY(160, 130, 92, 120));
   het_roller_set_font(roller, UI_BUF_COFFEE_FONT_ARIAL_11_BIN);
   het_roller_set_options(roller, days, 7);
   het_roller_set_inf(roller, true);
   het_roller_set_selected(roller, 2);
