组件说明
--------

het_led 提供 LVGL 风格的圆形状态指示灯，支持颜色、亮度、开关、翻转、闪烁和点击回调。

参数与选项
----------

.. list-table::
   :header-rows: 1

   * - 监听消息
     - 过滤条件
     - 结果
   * - MSG_CTP_CLICK
     - 触点命中 LED 圆形区域（中心命中判断）
     - 命中：触发回调并消费消息；未命中：透传消息

使用示例
--------

.. code-block:: c

   void *led = het_led_create(frm);
   het_led_set_geometry(led, HET_GEOMETRY(220, 70, 24, 24));
   het_led_set_color(led, 0, 185, 90);
   het_led_on(led);
   
   // 心跳闪烁：亮 120ms，灭 880ms
   het_led_set_blink(led, 120, 880);
