事件拦截过滤
------------

het_bar 是展示型控件，不注册触摸事件回调，不主动拦截 MSG_CTP\_\*。

组件说明
--------

het_bar 是 LVGL 风格的进度条组件，支持基础进度、对称进度和范围进度三种显示语义，适合音量、电量、缓冲进度、区间值显示等场景。

   * - 模式

使用示例
--------

.. code-block:: c

   void *bar = het_bar_create(frm, true);
   het_bar_set_geometry(bar, HET_GEOMETRY(160, 120, 180, 16));
   het_bar_set_range(bar, 0, 100);
   het_bar_set_mode(bar, HET_BAR_MODE_NORMAL);
   het_bar_set_style(bar, HET_BG_COLOR(80, 170, 255), HET_BG_COLOR(35, 40, 52));
   het_bar_set_radius(bar, 8);
   
   // 带动画更新到 65%
   het_bar_set_value(bar, 65, 220);
