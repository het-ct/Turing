SPI 串行外设接口（het_spi.h）

源文件：platform/hal/api/het_spi.h

概述

Het-X1 提供 SPI0/1/2，支持主机/从机模式、GPIO 复用和独立时钟控制；SPI2 还可服务于显示和图像传感器数据传输。

用法

配置频率、时钟极性/相位、位序、片选和引脚后初始化。根据设备协议选择写、读或全双工传输，异步模式需注册回调。

典型流程

  1. 获取默认配置或准备板级配置。

  2. 初始化外设并检查返回值。

  3. 执行读写、控制或回调注册操作。

  4. 停止异步来源并反初始化外设。

示例

#include "het_spi.h"

int spi_exchange(het_spi_id_t id, const uint8_t *tx,
                 uint8_t *rx, uint16_t len)
{
    het_spi_config_t cfg = het_spi_def_cfg();
    int ret = het_spi_init(id, &cfg);
    if (ret != HET_OK) return ret;
    het_spi_cs_enable(id, 1);
    ret = het_spi_transfer(id, tx, rx, len);
    het_spi_cs_enable(id, 0);
    het_spi_deinit(id);
    return ret;
}

API 介绍

Functions

het_spi_config_t het_spi_def_cfg(void)

获取 SPI 默认配置。

返回:

默认配置：同步 DMA、软件片选、单线模式。

int het_spi_init(het_spi_id_t id, const het_spi_config_t *config)

初始化 SPI 实例。

参数:

  • id -- [in] SPI 实例 ID。BT8790 目前仅支持 HET_SPI_ID_1。

  • config -- [in] SPI 配置。

返回:

HET_OK 表示成功，否则返回 HET_ERR_* 值。

int het_spi_deinit(het_spi_id_t id)

反初始化 SPI 实例。

参数:

  • id -- [in] SPI 实例 ID。

返回:

HET_OK 表示成功，否则返回 HET_ERR_* 值。

int het_spi_cs_enable(het_spi_id_t id, uint8_t en)

控制软件片选。

参数:

  • id -- [in] SPI 实例 ID。

  • en -- [in] 1 选中设备，0 释放设备。

返回:

HET_OK 表示成功，否则返回 HET_ERR_* 值。

int het_spi_write(het_spi_id_t id, const uint8_t *data, uint16_t len)

通过 DMA 写入数据。

参数:

  • id -- [in] SPI 实例 ID。

  • data -- [in] 发送缓冲区。

  • len -- [in] 发送字节数。

返回:

HET_OK 表示成功，否则返回 HET_ERR_* 值。

int het_spi_read(het_spi_id_t id, uint8_t *data, uint16_t len)

通过 DMA 读取数据。

参数:

  • id -- [in] SPI 实例 ID。

  • data -- [out] 接收缓冲区。

  • len -- [in] 接收字节数。

返回:

HET_OK 表示成功，否则返回 HET_ERR_* 值。

int het_spi_transfer(het_spi_id_t id, const uint8_t *tx_data, uint8_t *rx_data, uint16_t len)

执行 SPI 传输。完整的发送+接收传输实现为先写后读。

参数:

  • id -- [in] SPI 实例 ID。

  • tx_data -- [in] 发送缓冲区，或仅读时传 NULL。

  • rx_data -- [out] 接收缓冲区，或仅写时传 NULL。

  • len -- [in] 字节数。

返回:

HET_OK 表示成功，否则返回 HET_ERR_* 值。

int het_spi_register_cb(het_spi_id_t id, het_spi_cb_t cb, void *user_ctx)

注册异步传输回调。

参数:

  • id -- [in] SPI 实例 ID。

  • cb -- [in] 从 SPI ISR 调用的回调。

  • user_ctx -- [in] 回传给 cb 的用户上下文。

返回:

HET_OK 表示成功，否则返回 HET_ERR_* 值。

int het_spi_unregister_cb(het_spi_id_t id)

注销异步传输回调。

参数:

  • id -- [in] SPI 实例 ID。

返回:

HET_OK 表示成功，否则返回 HET_ERR_* 值。
