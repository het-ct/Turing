het_flex Elastic Layout Container

UI Components

include/het_flex.h

include/het_flex.h

Component Description

het_flex is a lightweight linear layout container used to arrange subitems along the spindle direction (rows/columns), supporting spindle allocation and cross axis alignment.

  • Suitable for the regular arrangement of controls of the same type, such as button groups, message bars, and status blocks.

  • Each sub-item can be set to fixed size, percentage size, or automatic size.

  • Elastic expansion within the remaining space can be achieved through grow.

API Introduction

void *het_flex_create(compo_form_t *frm)

Create a flex container object.

Parameter: frm Target form.

Return: void* Container handle, returns NULL on failure.

void het_flex_clear(void *obj)

Clear all items in the container.

Parameter: obj Flex container handle.

bool het_flex_add(void *obj, void *child, int16_t width, int16_t height, uint8_t grow)

Add an item with specified size and growth factor.

Parameters: obj Container handle; child Item object; width/height Item size; grow Growth factor.

Return: true on success; false on failure.

bool het_flex_add_pct(void *obj, void *child, uint8_t width_pct, uint8_t height_pct, uint8_t grow)

Add an item by percentage size.

Parameters: obj Container handle; child Item object; width_pct/height_pct Percentage size (recommended 0~100); grow Growth factor.

Return: true on success; false on failure.

void het_flex_update(void *obj)

Trigger layout update and recalculate item geometry.

Parameter: obj Container handle.

Set the container geometry.

Parameters: obj Container handle; rect Geometry information.

void het_flex_set_padding(void *obj, const het_pad_t padding)

Set container padding.

void het_flex_set_gap(void *obj, int16_t gap)

Set item gaps.

Parameters: obj Container handle; dir Direction; justify Main axis distribution; align Cross axis alignment.

Example

void *flex = het_flex_create(frm);
het_flex_set_geometry(flex, HET_GEOMETRY(160, 120, 220, 72));
het_flex_set_padding(flex, HET_PADDING(6, 8, 8, 6));
het_flex_set_gap(flex, 8);
het_flex_set_flow(flex,
                  HET_FLEX_DIR_ROW,
                  HET_FLEX_JUSTIFY_SPACE_BETWEEN,
                  HET_FLEX_ALIGN_CENTER);

void *btn_ok = het_button_create(frm->page, HET_BG_MODE_SC, 7);
void *btn_cancel = het_button_create(frm->page, HET_BG_MODE_SC, 7);

het_flex_add_pct(flex, btn_ok, 45, 100, 0);
het_flex_add_pct(flex, btn_cancel, 45, 100, 0);
het_flex_update(flex);
