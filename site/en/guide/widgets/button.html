Radio mechanism

Enable a mutually exclusive group via het_button_set_radio_group(obj, group_id); only one button in the same group can be selected at a time.

  • group_id = 0: disable radio mode (restore normal toggle).

  • group_id > 0: enable mutual exclusion; clicking the current button will deselect other selected buttons in the same group.

API Introduction

void * het_button_create(compo_form_t *frm, const het_bg_mode bg_mode)

Create button. bg_mode uses HET_BG_MODE_SC (rectangular background) or HET_BG_MODE_2D (image background).

Parameters: frm target form; bg_mode background mode.

Return: void* button handle, returns NULL on failure.

int het_button_event(void * obj, const void * const msg)

Reserved interface (currently returns 0). It is recommended to rely on the object system callback chain.

Parameters: obj button handle; msg input message object.

Return: int currently always 0.

Set position and size.

Example

static void on_btn(const het_event_t * const e)
{
    int st = het_button_get_state(e->original);
    (void)st;
}

void *btn = het_button_create(frm->page, HET_BG_MODE_SC, 7);
het_button_set_geometry(btn, HET_GEOMETRY(160, 120, 100, 40));
het_button_set_bg_style(btn, HET_BG_COLOR(30, 144, 255));
het_button_set_bg_radius(btn, 8, HET_RADIUS_DEFAULT);
het_button_set_text(btn, "确认");
het_button_set_font(btn, UI_BUF_COFFEE_FONT_ARIAL_11_BIN);
het_button_set_text_align(btn, HET_TEXT_ALIGN_CENTER, HET_PADDING(0, 0, 0, 0));
het_button_set_slot(btn, on_btn, NULL);

// radio 示例
het_button_set_radio_group(btn, 1);
