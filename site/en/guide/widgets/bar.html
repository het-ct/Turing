Event interception filter

het_bar is a display-type control, does not register touch event callbacks, and does not actively intercept MSG_CTP_*.

Component Description

het_bar is an LVGL-style progress bar component that supports three display semantics: basic progress, symmetrical progress, and range progress. It is suitable for scenarios such as volume, battery level, buffering progress, and interval value display.

void het_bar_set_value(void *obj, const int32_t value, const uint16_t duration)

Example

void *bar = het_bar_create(frm, true);
het_bar_set_geometry(bar, HET_GEOMETRY(160, 120, 180, 16));
het_bar_set_range(bar, 0, 100);
het_bar_set_mode(bar, HET_BAR_MODE_NORMAL);
het_bar_set_style(bar, HET_BG_COLOR(80, 170, 255), HET_BG_COLOR(35, 40, 52));
het_bar_set_radius(bar, 8);

// 带动画更新到 65%
het_bar_set_value(bar, 65, 220);
