Component Description

het_checkbox is an LVGL-style checkbox component with a double-layer structure: the outer main background frame shows the border color, and the inner sub-background reflects the checked state (solid color or image). The text is automatically arranged to the right of the checkbox.

Parameters and Options

Enumeration value

Creation Parameters

Description

HET_BG_MODE_SC

mode

Solid color fill, supports gradient animation for checked state, style configured via HET_BG_COLOR

HET_BG_MODE_2D

mode

Image (e.g., check mark icon), instant switch on checked state, style configured via HET_BG_IMG

API Introduction

het_checkbox_create

Create a checkbox component with a double-layer structure, the inner sub-background mode is specified by mode.

Parameters: frm - parent form; mode - HET_BG_MODE_SC (solid color) or HET_BG_MODE_2D (image)

Returns: void * pointer to the checkbox object, NULL on failure

het_checkbox_set_pos

Set the position of the checkbox, text is automatically arranged to the right of the checkbox.

Parameters: obj - checkbox object pointer; x - X coordinate of the checkbox center; y - Y coordinate of the checkbox center

het_checkbox_set_geometry

Set both position and size to quickly complete the checkbox layout.

Parameters: obj - checkbox object pointer; rect - geometry information, usually uses HET_GEOMETRY(x, y, w, h).

het_checkbox_set_box_size

Set the side length and border width of the checkbox (main background frame).

Parameters: obj - checkbox object pointer; size - outer frame side length (pixels), default 16; border - border width (pixels), 0 means inner layer fills the outer frame

het_checkbox_set_border_color

Set the color of the main background frame (border).

Parameters: obj - checkbox object pointer; color - border color (uint16_t RGB565)

het_checkbox_set_pad

Set the spacing between the checkbox and the text.

Parameters: obj - checkbox object pointer; pad - spacing (pixels), default 8

het_checkbox_set_font

Set the font resource for the checkbox, must be called before set_text.

Parameters: obj - checkbox object pointer; font - font resource address

het_checkbox_set_text

Set the text content of the checkbox.

Parameters: obj - checkbox object pointer; text - text content

Note: set_font must be called first, otherwise the text may be cleared.

het_checkbox_set_text_color

Set text color.

Parameters: obj - checkbox object pointer; color - text color (uint16_t RGB565)

Example

/* 纯色模式复选框，带渐变动画 */
void *cb = het_checkbox_create(frm, HET_BG_MODE_SC);
het_checkbox_set_pos(cb, 60, 120);
het_checkbox_set_box_size(cb, 20, 2);
het_checkbox_set_border_color(cb, COLOR_GRAY);
het_checkbox_set_radius(cb, 4);
het_checkbox_set_style(cb,
    (het_bg_res_t)HET_BG_COLOR(COLOR_BLUE),   /* 选中：蓝色填充 */
    (het_bg_res_t)HET_BG_COLOR(COLOR_BLACK));  /* 未选中：黑色填充 */
het_checkbox_set_anim_time(cb, 200);
het_checkbox_set_font(cb, (uint32_t)&my_font_16);
het_checkbox_set_text(cb, "同意用户协议");
het_checkbox_set_text_color(cb, COLOR_WHITE);
het_checkbox_set_pad(cb, 8);
het_checkbox_set_slot(cb, my_cb_handler, NULL);

/* 回调中读取状态 */
void my_cb_handler(void *obj, het_event_t *evt) {
    if (evt->type == HET_EVENT_VALUE_CHANGED) {
        bool checked = het_checkbox_get_checked(obj);
    }
}
