Component Description

het_roller is used for up/down scrolling selection within a limited set of options, commonly in scenarios like date, time, or enum configuration.

Parameters and Options

Listen for messages

Filter conditions

Results

MSG_CTP_TOUCH

Touch point hits the roller background area

Hit: enter drag and consume message; Miss: pass message through

MSG_CTP_MOVE_*、MSG_CTP_LONG*、MSG_CTP_SHORT_*、MSG_CTP_CLICK、MSG_CTP_LONG_LIFT

dragging=true

Update displacement during drag; release to start inertia/snapping; consume message

Other messages

If still dragging, final release is also executed

Consume message after final release, otherwise pass message through

Parameters and Options

Mode

Semantics

Applicable Scenarios

HET_ROLLER_PHYSICS_SNAP

No inertia, directly snap after release

Precise configuration page

HET_ROLLER_PHYSICS_INERTIA

Snap after sliding by speed

Universal list scrolling

HET_ROLLER_PHYSICS_ELASTIC

Inertia boundary damping/rebound

More natural touch feeling

API Introduction

void *het_roller_create(compo_form_t *frm, uint8_t visible_cnt)

Create roller, specify number of visible rows.

Parameters: frm target form; visible_cnt number of visible rows, using odd numbers is recommended.

Returns: void* roller component handle, returns NULL if failed.

void het_roller_set_geometry(void *obj, const rect_t rect)

Set center coordinates and width/height, row height will be automatically calculated as hei / visible_cnt.

Parameters: obj roller handle; rect geometry information.

void het_roller_set_options(void *obj, const char **opts, uint16_t opt_cnt)

Set option string array. Note that the string’s lifetime should cover the control’s lifetime.

Parameters: obj roller handle; opts option string array; opt_cnt number of options.

void het_roller_set_selected(void *obj, uint16_t idx)

No animation, directly select the specified item.

Parameters: obj roller handle; idx target index, 0-based.

void het_roller_set_row_height(void *obj, int16_t row_h)

Manually set row height.

Parameters: obj roller handle; row_h height of each row.

void het_roller_set_color(void *obj, uint16_t bg_color, uint16_t sel_color, uint16_t text_color, uint16_t sel_text_color)

Set background, selected bar, normal text, and selected text colors.

Parameters: obj roller handle; bg_color background color; sel_color selected bar color; text_color normal text color; sel_text_color selected text color.

void het_roller_set_font(void *obj, uint32_t font)

Set font, it is recommended to call before set_options.

Parameters: obj roller handle; font font resource ID.

void het_roller_set_radius(void *obj, uint16_t radius)

Set the background corner radius.

Parameters: obj roller handle; radius corner radius.

void het_roller_set_inf(void *obj, bool inf)

Enable/disable infinite loop scrolling.

Parameters: obj roller handle; inf whether to enable infinite loop.

void het_roller_set_physics(void *obj, const het_roller_physics_t *physics)

Set physical effects, pass NULL to restore default SNAP.

Parameters: obj roller handle; physics pointer to physics configuration, pass NULL to restore default configuration.

void het_roller_set_slot(void *obj, event_cb slot, void *user_data)

Register callback, triggered after snap completes and value changes HET_EVENT_VALUE_CHANGED.

Parameters: obj roller handle; slot callback function; user_data user pointer passed through.

void het_roller_set_visible(void *obj, bool visible)

Set visibility.

Parameters: obj roller handle; visible whether to show.

uint16_t het_roller_get_selected(const void *obj)

Get the currently selected index (0-based).

Parameters: obj roller handle.

Return: uint16_t Index of the currently selected item.

const char *het_roller_get_selected_str(const void *obj)

Get the currently selected text.

Parameters: obj roller handle.

Returns: const char* String pointer for the currently selected item.

Example

const het_roller_physics_t p = HET_ROLLER_PHYSICS_CONFIG(
    HET_ROLLER_PHYSICS_INERTIA,
    180,   // snap_ms
    3600,  // decel
    5,     // max_throw_rows
    96     // edge_resist
);
het_roller_set_physics(roller, &p);

static const char *days[] = {"一", "二", "三", "四", "五", "六", "日"};

void *roller = het_roller_create(frm, 5);
het_roller_set_geometry(roller, HET_GEOMETRY(160, 130, 92, 120));
het_roller_set_font(roller, UI_BUF_COFFEE_FONT_ARIAL_11_BIN);
het_roller_set_options(roller, days, 7);
het_roller_set_inf(roller, true);
het_roller_set_selected(roller, 2);
