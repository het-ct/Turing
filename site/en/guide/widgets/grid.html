het_grid Grid layout container

UI Components

include/het_grid.h

include/het_grid.h

Component Description

het_grid is a two-dimensional grid layout container that places items into specified cells via column and row templates, supporting column/row spanning.

  • It is suitable for dashboards, menu matrices, information panels, and other regular grid scenarios.

  • First define the template (number of columns/rows), then bind controls to cell coordinates.

  • Inequal-sized areas can be created through row and column spanning.

API Introduction

void *het_grid_create(compo_form_t *frm)

Create a grid container object.

Parameter: frm Target form.

Return: void* Container handle, returns NULL on failure.

void het_grid_clear(void *obj)

Clear all items in the grid.

Parameter: obj Grid container handle.

bool het_grid_add(void *obj, void *child, uint8_t col, uint8_t row, uint8_t col_span, uint8_t row_span)

Add an item to the specified cell and set column/row spanning.

Parameter: obj container handle; child sub-item object; col/row starting column index; col_span/row_span span.

Return: true on success; false on failure.

bool het_grid_add_cell(void *obj, void *child, uint8_t col, uint8_t row)

Add subterms to a single mesh cell (with a fixed span of 1x1).

Parameter: obj container handle; child sub-item object; col/row target column index.

Return: true on success; false on failure.

void het_grid_update(void *obj)

Triggers layout updates and recalculates all sub-geometry.

Parameter: obj Container handle.

void het_grid_set_geometry(void *obj, const rect_t rect)

Set the container geometry.

Parameters: obj Container handle; rect Geometry information.

void het_grid_set_padding(void *obj, const het_pad_t padding)

Set container padding.

Parameters: obj Container handle; padding Padding values.

void het_grid_set_gap(void *obj, int16_t col_gap, int16_t row_gap)

Set column spacing and row spacing.

Parameter: obj container handle; col_gap Column spacing; row_gap Line spacing.

void het_grid_set_template(void *obj, uint8_t cols, uint8_t rows)

Set the grid template (number of columns and rows).

Parameter: obj container handle; cols: Number of columns; rows (row count).

Example

void *grid = het_grid_create(frm);
het_grid_set_geometry(grid, HET_GEOMETRY(160, 120, 220, 160));
het_grid_set_padding(grid, HET_PADDING(8, 8, 8, 8));
het_grid_set_gap(grid, 6, 6);
het_grid_set_template(grid, 3, 2);

void *icon = het_image_create(frm, HET_BG_MODE_2D);
void *name = het_label_create(frm, NULL, 32);
void *value = het_label_create(frm, NULL, 16);

het_grid_add(grid, icon, 0, 0, 1, 2);      // 左侧图标跨两行
het_grid_add_cell(grid, name, 1, 0);       // 标题
het_grid_add(grid, value, 1, 1, 2, 1);     // 数值横跨两列

het_grid_update(grid);
