Component Description

het_slider based on het_bar expansion, offering draggable knobs for interactive numerical selection (volume, brightness, progress tracking, etc.).

Parameters and Options

Listen for messages

Filter conditions

Results

MSG_CTP_TOUCH/CLICK/LONG/LONG_*/SHORT_*

Contact hit: slider hit area (track and knob size should be a larger range)

update dragging status

: MSG_CTP_MOVE_RT/LT/UP/DN (and default branches):

dragging=true and can retrieve the current contact

When updatable: consume messages and refresh values; Otherwise: Pass-through

API Introduction

void * het_slider_create(compo_form_t *frm)

message creates a slider component.

Parameter: frm Target form.

Returns: void* slider component handle; failure returns NULL.

void het_slider_set_geometry(void *obj, const rect_t rect)

Set position and size.

Parameter: obj slider handle; rect geometric information.

void het_slider_set_range(void *obj, const int32_t min, const int32_t max)

Set the value range.

Parameter: obj slider handle; min is the minimum value; max.

void het_slider_set_value(void *obj, const int32_t value)

Set the value without triggering a callback.

Parameter: obj slider handle; value.

void het_slider_set_value_notify(void *obj, const int32_t value, void *param)

Set values and trigger value change events; param can propagate business context.

Parameter: obj slider handle; value: target value; param callback to the transmission parameter.

void het_slider_set_knob_size(void *obj, const uint8_t size)

Set the knob size.

Parameter: obj slider handle; Size: knob size.

void het_slider_set_knob_color(void *obj, const uint16_t color)

Set the knob color (RGB565).

Parameter: obj slider handle; color knob.

void het_slider_set_color(void *obj, const uint16_t knob_color, const uint16_t indic_color, const uint16_t bg_color)

Set knobs, indicators, and track background colors all at once.

Parameter: obj slider handle; knob_color Knob color; indic_color Colors of areas already visited; bg_color Track background color.

void het_slider_set_radius(void *obj, const uint16_t radius)

Set track fillets.

Parameter: obj slider handle; radius of the orbital fillet.

void het_slider_set_indic_padding(void *obj, const het_pad_t padding)

Set the indicator to retract to control the distance between the area already walked and the track edge.

Parameter: obj slider handle; Padding indicator: Margin inside the indicator.

void het_slider_set_orientation(void *obj, const het_bar_orientation orientation)

Set it horizontally or vertically.

Parameter: obj slider handle; orientation enumeration direction.

void het_slider_set_slot(void *obj, event_cb slot, void *user_data)

Register callback, event code is HET_EVENT_VALUE_CHANGED.

Parameters: obj slider handle; slot callback function; user_data user pass-through pointer.

void het_slider_set_visible(void *obj, const bool visible)

Set visibility.

Parameters: obj slider handle; visible whether to display.

int32_t het_slider_get_value(const void *obj)

Get the current value.

Parameters: obj slider handle.

Return: int32_t current value.

int32_t het_slider_get_min(const void *obj) / int32_t het_slider_get_max(const void *obj)

Get the minimum / maximum value.

Parameters: obj slider handle.

Returns: int32_t currently configured minimum or maximum value.

Example

static void on_volume_changed(const het_event_t * const e)
{
    void *slider = e->original;
    int32_t vol = het_slider_get_value(slider);
    (void)vol;
}

void *slider = het_slider_create(frm);
het_slider_set_geometry(slider, HET_GEOMETRY(160, 152, 180, 22));
het_slider_set_range(slider, 0, 100);
het_slider_set_color(slider, COLOR_WHITE, make_color(67, 145, 255), make_color(45, 52, 66));
het_slider_set_knob_size(slider, 18);
het_slider_set_value(slider, 40);
het_slider_set_slot(slider, on_volume_changed, NULL);
