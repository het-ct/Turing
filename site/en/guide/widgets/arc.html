Component Description

het_arc is an LVGL-style arc (gauge) component, consisting of three layers: background track arc, indicator arc, and knob. It supports three growth modes and touch drag interaction, suitable for volume knobs, gauges, battery rings, and other scenarios.

Growth Modes

Parameters and Options

Enumeration value

Description

HET_ARC_MODE_NORMAL

Grow forward from the start of the background arc (default)

HET_ARC_MODE_REVERSE

Grow backward from the end of the background arc

HET_ARC_MODE_SYMMETRICAL

Expand outward from the midpoint of the background arc

API Introduction

het_arc_create

Create an arc component.

Parameters: frm Parent form; enable_anim Whether to enable value animation

Returns: void* arc object pointer, returns NULL on failure

het_arc_set_geometry

Set the geometry of the arc.

Parameters: obj Arc object pointer; rect Area (x/y as center point, it is recommended that width and height be equal)

het_arc_set_width

Set the arc width (difference between inner and outer radius).

Parameters: obj Arc object pointer; width Arc width (pixels), default 10

het_arc_set_knob_size

Set the knob diameter, 0 means hide the knob.

Parameters: obj Arc object pointer; size Diameter (pixels), default 20

het_arc_set_bg_angles

Set the start and end angles of the background arc, unit 0.1°, 0° is to the right horizontally, clockwise growth.

Parameters: obj Arc object pointer; start Start angle (0.1°); end End angle (0.1°)

Example: 270° gauge → start=1350, end=450

het_arc_set_range

Set the value range.

Parameters: obj Arc object pointer; min Minimum; max Maximum

het_arc_set_value

Set the current value without triggering event callbacks. Value is automatically clamped to the min~max range.

Parameters: obj Arc object pointer; value Target value

Note: if enable_anim was enabled during creation, it will smooth transition, otherwise instant refresh.

het_arc_set_value_notify

Set the current value and trigger VALUE_CHANGED event callback.

Parameters: obj arc object pointer; value target value; param event parameter passed through to the callback

het_arc_set_mode

Set the indicator arc growth mode.

Parameters: obj arc object pointer; mode HET_ARC_MODE_NORMAL / REVERSE / SYMMETRICAL

het_arc_set_adjustable

Set whether touch dragging to adjust the value is allowed.

Parameters: obj arc object pointer; adjustable true=draggable (default), false=display only

het_arc_set_anim_time

Set the duration of the value gradient animation. If animation is not enabled at creation, this interface is invalid.

Parameters: obj arc object pointer; ms animation duration (milliseconds), default 300

het_arc_set_color

Set the colors of the indicator arc, background track, and knob.

Parameters: obj arc object pointer; indic_color indicator arc color; track_color background track color; knob_color knob color

het_arc_set_slot

Set event callback, triggered by touch dragging or set_value_notify when VALUE_CHANGED occurs.

Parameters: obj arc object pointer; cb callback function; user_data user data

het_arc_set_visible

Set the visibility of the arc.

Parameters: obj arc object pointer; visible whether visible

het_arc_get_value

Get the current value.

Parameters: obj arc object pointer

Returns: int16_t current value

het_arc_get_min

Get the minimum value.

Parameters: obj arc object pointer

Returns: int16_t minimum value

het_arc_get_max

Get the maximum value.

Parameters: obj arc object pointer

Returns: int16_t maximum value

Example

/* 创建 270° 仪表盘，带动画 */
void *arc = het_arc_create(frm, true);
het_arc_set_geometry(arc, (rect_t){120, 120, 200, 200});
het_arc_set_bg_angles(arc, 1350, 450);   /* 135°~45°，单位 0.1° */
het_arc_set_range(arc, 0, 100);
het_arc_set_width(arc, 12);
het_arc_set_knob_size(arc, 20);
het_arc_set_color(arc, COLOR_BLUE, COLOR_GRAY, COLOR_WHITE);
het_arc_set_slot(arc, my_arc_cb, NULL);

/* 设值并触发回调 */
het_arc_set_value_notify(arc, 75, NULL);

/* 回调中读取当前值 */
void my_arc_cb(void *obj, het_event_t *evt) {
    if (evt->type == HET_EVENT_VALUE_CHANGED) {
        int16_t v = het_arc_get_value(obj);
    }
}
