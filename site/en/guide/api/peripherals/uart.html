UART Asynchronous Serial (het_uart.h)

Source file: platform/hal/api/het_uart.h

Overview

AB579X’s UART0/1 support general asynchronous communication, flexible GPIO mapping, and Key Match; the chip also provides high-speed HSUART with CTS/RTS, DMA, and circular buffer capability.

Usage

Set instance, pins, and baud rate via board-level configuration. After initialization, call read and write interfaces; for asynchronous reception, register callbacks first, and unregister callbacks and de-initialize before closing the UART.

Typical Procedure

  1. Obtain the default configuration or prepare the board-level configuration.

  2. Initialize the peripheral and check the return value.

  3. Perform read/write, control, or callback registration operations.

  4. Stop asynchronous sources and deinitialize the peripheral.

Examples

#include "het_uart.h"

int uart_send(het_uart_id_t id, const uint8_t *data, uint16_t len)
{
    het_uart_handle_t uart = het_uart_def_cfg();
    int ret = het_uart_init(&uart);
    if (ret != HET_OK) return ret;
    ret = het_uart_write(id, data, len);
    het_uart_deinit(id);
    return ret;
}
