PWM Pulse Width Modulation (het_pwm.h)

Source file: platform/hal/api/het_pwm.h

Overview

AB579X’s Timer3/4 support dual-channel PWM, and Timer5 supports up to 6 PWM channels, which can be used for backlight, buzzer, motor, and lighting effects control.

Usage

Choose timer channels and pins via board-level configuration. After initialization, set frequency and per mille duty cycle, then start output; check return values when modifying parameters.

Typical Procedure

  1. Obtain the default configuration or prepare the board-level configuration.

  2. Initialize the peripheral and check the return value.

  3. Perform read/write, control, or callback registration operations.

  4. Stop asynchronous sources and deinitialize the peripheral.

Examples

#include "het_pwm.h"

int pwm_start_output(het_pwm_id_t id, uint32_t hz, uint32_t duty_permile)
{
    het_pwm_handle_t pwm = het_pwm_def_cfg();
    int ret = het_pwm_init(&pwm);
    if (ret != HET_OK) return ret;
    if ((ret = het_pwm_set_frequency(id, hz)) != HET_OK) return ret;
    if ((ret = het_pwm_set_duty(id, duty_permile)) != HET_OK) return ret;
    return het_pwm_start(id);
}
