het_physics General Physical Parameter Description

UI Components

include/het_physics.h

include/het_physics.h

Class Diagram

Usage Timing

Purpose

het_physics provides reusable drag/release physical semantics for shared consistent tactile feedback in interactive components such as wheels, lists, and page switching.

Physical Mode

Parameter Structure

Default Macros:

Result expansion: By default, HET_PHYSICS_SNAP is used, with adsorption duration 180ms, deceleration 3600 px/s^2, and boundary damping 96.

Configuration Example

Macro Parameters: HET_PHYSICS_CONFIG(mode, snap_ms, decel, edge_resist) takes mode, adsorption duration, deceleration, and boundary damping in order.

Usage Suggestion: If you only want to slightly adjust the feel, it is recommended to make small modifications to snap_ms and decel based on the default values, avoiding changing all parameters at once.

Parameters and Options

Enumeration

Description

HET_PHYSICS_SNAP

No inertia, directly adsorbs/docks after release

HET_PHYSICS_INERTIA

Continue sliding for a distance based on release speed

HET_PHYSICS_ELASTIC

Add boundary damping/rebound semantics on the basis of inertia

Parameters and Options

Fields

Type

Description

mode

het_physics_mode

Physical mode, determines whether adsorption, inertia, or interaction semantics with rebound are used.

snap_ms

uint16_t

Animation duration for final adsorption to target position, in ms; 0 usually falls back to the component’s default value.

decel

uint16_t

Deceleration during inertia phase; the larger the value, the faster it stops, commonly used in INERTIA / ELASTIC modes.

edge_resist

uint8_t

Boundary damping strength; the larger the value, the harder it is to drag beyond the boundary, mainly used in ELASTIC mode.

Example

typedef struct {
    het_physics_mode mode; // SNAP / INERTIA / ELASTIC
    uint16_t snap_ms;      // 吸附动画时长（ms）
    uint16_t decel;        // 惯性减速度（px/s^2）
    uint8_t edge_resist;   // 边界阻尼 1..255
} het_physics_t;

#define HET_PHYSICS_DEFAULT  { HET_PHYSICS_SNAP, 180U, 3600U, 96U }

// 通用配置宏
het_physics_t p = HET_PHYSICS_CONFIG(
    HET_PHYSICS_INERTIA,
    180,   // snap_ms
    3600,  // decel
    96     // edge_resist
);

// 在具体组件里使用（例如 roller）
het_roller_physics_t rp = {
    .base = p,
    .max_throw_rows = 5,
};
het_roller_set_physics(roller, &rp);
