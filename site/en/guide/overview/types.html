het_event_t — Event structure

callback signature: event_cb Receives pointers to read-only event objects; the business side usually should not modify its internal fields.

Common macro parameters: evt is const het_event_t *; HET_EVT_GET_POS Applicable to coordinate events, HET_EVT_GET_CODE Used to extract event codes, HET_EVT_GET_USER_DATA Used to retrieve the context at registration.

Field packaging event type and event code; The lower 2 bits are type, and the remaining high bits are code.

Example

typedef struct {
    void       *original;
    void       *user_data;
    const void *param;
    uint32_t   flags;      // bit0-1: type, bit2-31: code
} het_event_t;

typedef void (*event_cb)(const het_event_t * const e);

// 便捷宏
#define HET_EVT_GET_POS(evt)        (const het_point_t *) evt->param
#define HET_EVT_GET_TYPE(evt)       (het_event_type) (evt->flags & 0x03)
#define HET_EVT_GET_CODE(evt)       (het_event_code) (evt->flags >> 2)
#define HET_EVT_GET_USER_DATA(evt)  (evt->user_data)

typedef struct { s16 x, y, wid, hei; } rect_t;
typedef struct { int8_t top, left, right, bottom; } het_pad_t;
typedef struct { int16_t x, y; } het_point_t;

// 快捷宏
#define HET_GEOMETRY(x, y, w, h)  (const rect_t){x, y, w, h}
