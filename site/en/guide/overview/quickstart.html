GUI Quick Start Workflow and Bus Principle

UI Components

Usage Process

  • Initialize the object system: het_obj_init().

  • Create page container: compo_form_create(true).

  • Create controls and set geometry/style: it is recommended to set geometry first, then font and text.

  • Bind callbacks to interactive controls: *_set_slot(obj, cb, user_data).

  • Continuously dispatch messages in the main loop: het_obj_update(&msg, func_message).

  • If animation or state refresh is needed, periodically call control setting interfaces in process.

Bus Management Principle

This GUI framework adopts the event bus method of ‘unified message entry, control tree dispatch.’ Touch messages (MSG_CTP_*) are extracted by the main loop and handed over to the object system; controls decide the handling strategy based on hit and state.

Notes

  • It is recommended to set the font first before writing text to avoid abnormal text states in some components.

  • The x/y of most components uses center coordinates; do not interpret them as top-left coordinates during layout.

  • Distinguish between set_value and set_value_notify: the latter triggers business callbacks.

  • If the interface parameter type is het_bg_res_t, passing color values and passing image resources are not the same thing; the corresponding construction macro must be used.

  • Try to only do lightweight processing in callbacks, and put time-consuming logic into business tasks.

  • When troubleshooting event issues, first check the hit conditions and filtering rules; do not suspect callback registration first.

Simple demonstration sample (two-stage, refer to func_idle)

It is recommended to organize according to the “two-stage” approach: the first stage is responsible for creation and entry, and the second stage is responsible for periodic processing and message distribution. The structure can directly align with func_idle_enter / func_idle_process / func_idle_message.

Parameters and Options

Category

Typical Interface

It is recommended to

Creation

het_xxx_create(…)

On successful creation, returns a component handle; on failure, usually returns NULL. It is recommended to immediately complete geometry and basic styles after creation.

Layout

set_geometry / set_pos / set_size

Prefer using set_geometry to determine position and size in one go to avoid intermediate state flicker caused by step-by-step setting.

Style

set_color / set_style / set_radius / set_font

For font-type components, it is recommended to set the font first before writing the text; for background-type components, pay attention to distinguishing between pure color values and resource descriptor types.

Events

set_slot

In callbacks, retrieve the event source handle via e->original and retrieve the context passed through during registration via e->user_data.

Status Change

set_value / set_value_notify

When the business only wants to synchronize the UI, prioritize using the silent interface; when external logic needs to be triggered, use the notify version.

Query

get_xxx

Getters generally have no side effects and are suitable for reading the current state of the control in a callback, rather than caching a duplicate state yourself.

Example

static void *g_icon;

  static void on_slider(const het_event_t * const e)
  {
    void *slider = e->original;
    int32_t angle = het_slider_get_value(slider);
    het_image_set_rotation(g_icon, angle * 10); // 0.1° 单位
  }

  /* 第一段：enter/create（一次性） */
  static compo_form_t *demo_form_create(void)
  {
    het_obj_init();
    compo_form_t *frm = compo_form_create(true);

    g_icon = het_image_create(frm, HET_BG_MODE_2D);
    het_image_set_src(g_icon, HET_BG_IMG(UI_BUF_COFFEE_ITALIANBALL_BIN));
    het_image_set_pos(g_icon, 80, 80);

    void *slider = het_slider_create(frm);
    het_slider_set_geometry(slider, HET_GEOMETRY(120, 190, 180, 12));
    het_slider_set_range(slider, 0, 360);
    het_slider_set_slot(slider, on_slider, NULL);

    return frm;
  }

  void demo_enter(void)
  {
    func_cb.frm_main = demo_form_create();
  }

  /* 第二段：process/message（循环内） */
  void demo_process(void)
  {
    // 这里可放动画刷新、轮询状态同步等轻量逻辑
  }

  void demo_message(u16 msg)
  {
    het_obj_update(&msg, func_message);
  }

  void demo_run(void)
  {
    demo_enter();

    while (func_cb.sta == FUNC_IDLE) {
      demo_process();
      demo_message(msg_dequeue());
    }
  }
