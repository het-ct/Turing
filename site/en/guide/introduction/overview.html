MCU Platform Overview

This manual is designed for teams developing embedded products using HET x1 MCUs, board-level HAL, GUI controls, and CBB capability components. It does not describe application processor workflows such as Linux user space, Android Framework, ADB/Fastboot, or Yocto/Buildroot.

Platform Range

  • : Chips and Boots: RISC-V CPU, NPU/GPU, on-chip storage, boot chain, and security boundaries.

  • Board Fit Compatibility: Power, clock, reset, pin multiplexing, display, audio, sensors, and wireless devices.

  • Peripheral HAL: Provides interfaces such as GPIO, ADC, IIC, SPI, LCD, PWM, Timer, UART, QDEC, etc. according to public header files.

  • Middleware and CBB: GUI, network/Bluetooth, algorithms, logs, secure storage, OTA, and category workflows.

  • Product Engineering: Engineering configuration, compilation, programming, serial diagnostics, regression testing, and package release.

Get started、Examples

reading path

  1. in Environment Installation and Project Compilation install tools and compile an existing project.

  2. Read Chip architecture and memory to understand .com/.bank and real-time paths.

  3. Enter the Board-level Adaptation: according to the development board, confirm pins and resource allocation.

  4. Use the corresponding HAL page to complete a peripheral closed-loop, then combine the UI or CBB.

  5. Finally, read Reference’s verification, faults, and release requirements.
