The development kit and the first power-on

X1 core board are used to first validate software, display, audio, sensor, and communication capabilities before moving on to the product board design. The current manual provides the main interface and pin information for the S1 core board; The complete configuration data for S2 and S3 still needs to be supplemented.

preparation list

  • X1 core board, baseboard, and display module with the engineering configuration.

  • Stable power supply, USB/serial cable, serial debugging tools, and target firmware.

  • Installed compilation toolchains, Python 3, and make are Environment Installation and Project Compilation.

  • Records of board versions, chip packages, LCD/CTP models, and serial port instances.

Turn off the power supply for the first

  1. time, check the polarity, jump cap, ribbon wire direction, and display/touch interface voltage.

  2. Only connect the debugging serial port and power supply; after powering on, confirm no abnormal overheating or overcurrent.

  3. Open the serial terminal and record the reset reason, firmware version, and board type; Current serial port parameters are subject to the target project configuration.

  4. Compile projects/watch320 and confirm the generation of Output/bin/app.dcf.

  5. After burning, the boot log, display, touch, audio, and the peripherals required by the product are verified in sequence.

Warning

The pins and onboard components of S1/S2/S3 may differ. Pin reuse, screen parameters, and power control in the project must match the physical version; do not directly reuse the configuration of another board.

For an overview of the current data boundary

  • S1 pins and packages, see Packages and development boards.

  • For power supply and board level inspections, see Electrical characteristics and design limits and Reference circuits and review checklist.

  • Serial port encrypted programming tools, connection parameters, and fault recovery process: To be developed.

  • S2/S3 Complete schematics, pin lists, and directly compilable board-level projects: To be developed.
