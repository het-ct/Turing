FAQ

: This page summarizes common MCU SDK issues in the order of “phenomenon, inspection, handling.” When submitting your question, please provide the SDK version, board version, full build log, boot log, and reproducible steps.

Compiler or make not found

** Check: Run the toolchain version command, make --version, and python --version in the new terminal.

Handling: Make sure the tool directory has added PATH and that the project path does not contain any special characters that the script cannot handle. Re-execute python gen-srclist.py before compile; detailed steps are shown in Environment Installation and Project Compilation.

Compilation successful but no app.dcf

Check: Confirm that the current directory is the target project and check for the first compilation error, rather than just looking at the end of the log.

Processing: The object file is located at projects/<project>/Output/bin/app.dcf by default. If the directory does not exist, check whether the inclist.mk and project function switches are generated by the current configuration.

Peripheral Initialization Failure

Check: Records API return values, peripheral instances, pin reuse, clock, power, bus address, and initialization order.

Processing: First, run the minimal HAL example, then layer by layer access device drivers and services. Inlets for both the inner and outer components are shown in Peripheral HAL (on-chip peripherals), and the board-level adaptation is shown in Board-level Adaptation:.

Normal display but no touch response

Check: Separately verify touch power, reset, interrupt, IIC address, and coordinate direction, and confirm that display and touch are not reusing the same resource.

Processing: First print the original touch coordinates, then import the UI event; Simultaneously check coordinate conversion when rotating the screen. See the control event model in UI widgets.

**Check if you cannot start after upgrading

**: Keep the upgrade log, verify target partition, firmware integrity, signature, board version, and trial run confirmation status.

Handling: Stop repeatedly overwriting the startable partition and restore the OTA update abnormal path. Forced recovery operation and partition recovery package for mass-produced burners: To be developed.
