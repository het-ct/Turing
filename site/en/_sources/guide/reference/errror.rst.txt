统一错误模型
------------

het_err_t 是 int32_t。接口返回值约定为：ret > 0 表示成功（通常是传输字节数或 1），ret == 0 表示失败或没有进展，ret < 0 表示带严重级别、层级、模块和明细的结构化错误。

参考 het_button.c：事件返回值与错误码的边界
-------------------------------------------

platform/middlewares/gui/components/src/het_button.c 是组件事件处理示例。它使用 HET_OBJ_RET_CONSUMED 和 HET_OBJ_RET_PASS 表示消息是否被当前对象消费，这类返回值是事件分发结果，不是 het_err_t 错误码。

按钮实现通过 HET_CAST_OBJ 校验对象、更新状态并调用 het_event_notify 派发事件；如果底层 HAL 调用失败，应在 HAL/API 边界返回对应 HET_ERR\_\*，由上层事件处理器决定记录、重试、降级或转成业务消息。

设计与使用约束
--------------

* 新增模块错误优先使用 HET_ERR_MAKE(sev, layer, module, detail)，不要随意返回未分类负数。

* 错误层级应反映产生错误的实际层，不应因为调用方位于 App 就把 HAL 错误改写成 APP 层错误。

* 跨层转发时保留原始 het_err_t，需要补充上下文时使用日志或包装结构，不要丢失 severity/layer/module/detail。

* 回调、事件和 ISR 场景要明确错误码的线程上下文与生命周期；不要在 ISR 中执行阻塞恢复。

* 每个新增错误明细应同步更新对应模块头文件、文档和测试用例。

   * - 字段
     - 宏/范围
     - 含义
   * - Severity
     - HET_ERR_SEV_SHIFT = 28，掩码 0x70000000
     - INFO、WARN、ERROR、FATAL。
   * - Layer
     - HET_ERR_LAYER_SHIFT = 24，掩码 0x0F000000
     - COMMON、HAL、BSP、DRIVER、OS、APP。
   * - Module
     - HET_ERR_MODULE_SHIFT = 16，掩码 0x00FF0000
     - COMMON、GPIO、UART、IIC、SPI、Timer、PWM、ADC、DAC、SYS、DMA、CLOCK、LCD。
   * - Detail
     - 掩码 0x0000FFFF
     - 模块内具体错误原因。

.. code-block:: c

   int het_button_event(void * obj, const void * const msg)
   {
       return 0;
   }
   
   static het_obj_ret het_button_send(het_button_t *obj,
                                      const het_event_code signal,
                                      het_event_t *const evt)
   {
       if (het_obj_check_center(widget_get_absolute(obj->parent.src.obj),
                                *(const point_t *)HET_EVT_GET_POS(evt))) {
           het_event_notify(&obj->cb, obj, HET_EVENT_TYPE_NORMAL,
                            signal, evt->param);
           return HET_OBJ_RET_CONSUMED;
       }
       return HET_OBJ_RET_PASS;
   }

.. code-block:: c

   #include "het_err.h"
   #include "het_gpio.h"
   
   int init_button_gpio(void)
   {
       het_gpio_handle_t cfg = het_gpio_def_cfg();
       het_err_t ret = het_gpio_init(&cfg);
       if (HET_ERR_IS_NEG(ret)) {
           uint32_t severity = HET_ERR_GET_SEVERITY(ret);
           uint32_t layer = HET_ERR_GET_LAYER(ret);
           uint32_t module = HET_ERR_GET_MODULE(ret);
           uint32_t detail = HET_ERR_GET_DETAIL(ret);
           log_error("GPIO init failed: sev=%u layer=%u module=%u detail=0x%04x",
                     severity, layer, module, detail);
           return ret;
       }
       return HET_OK;
   }
   
   /* 对于返回传输数量的 API，按其头文件约定判断： */
   int send_frame(const uint8_t *data, uint16_t len)
   {
       int ret = het_spi_write(HET_SPI_ID_1, data, len);
       if (ret < 0) {
           /* 可按 HET_ERR_GET_* 解析结构化错误。 */
           return ret;
       }
       return ret; /* ret > 0 通常表示成功传输的字节数。 */
   }
