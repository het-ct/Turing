GPIO output example
===================

This example initializes GPIO using the public HAL. Start with the default
configuration, apply the board-specific settings through the board layer, then
check every return value before continuing with application logic.

Prerequisites
-------------

* The selected pin is connected to an LED or another output device.
* Board initialization and pin multiplexing have completed before this code
  runs.
* Refer to :doc:`../api/peripherals/gpio` for the exact configuration fields supported by the
  current SDK release.

Example
-------

.. code-block:: c

   #include "het_gpio.h"
   #include "het_err.h"

   int board_led_init(void)
   {
       het_gpio_handle_t cfg = het_gpio_def_cfg();

       het_err_t ret = het_gpio_init(&cfg);
       if (HET_ERR_IS_NEG(ret)) {
           return (int)ret;
       }
       return HET_OK;
   }

Workflow
--------

#. Obtain the default configuration with ``het_gpio_def_cfg()``.
#. Apply the target board's pin, mode, and level settings through its board
   configuration layer.
#. Call ``het_gpio_init()`` and handle an error before accessing the device.
#. Deinitialize or release the peripheral according to the matching HAL API
   when the application no longer uses it.

The board configuration type is opaque in the public API. Use the target
board's configuration interface rather than assuming internal structure field
names in application code.
