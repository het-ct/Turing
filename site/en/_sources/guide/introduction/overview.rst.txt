MCU 平台概述
============

本手册面向使用 HET x1 MCU、板级 HAL、GUI 控件和 CBB 能力组件开发嵌入式产品的团队。
它不描述 Linux 用户空间、Android Framework、ADB/Fastboot 或 Yocto/Buildroot 等应用处理器流程。

平台范围
--------

* **芯片与启动**：RISC-V CPU、NPU/GPU、片上存储、启动链和安全边界。
* **板级适配**：电源、时钟、复位、引脚复用、显示、音频、传感器和无线器件。
* **外设 HAL**：按公开头文件提供 GPIO、ADC、IIC、SPI、LCD、PWM、Timer、UART、QDEC 等接口。
* **中间件与 CBB**：GUI、网络/蓝牙、算法、日志、安全存储、OTA 和品类流程。
* **产品工程**：工程配置、编译、烧录、串口诊断、回归测试和发布包。

阅读路径
--------

1. 在 :doc:`../get-started/environment` 安装工具并编译一个现有工程。
2. 阅读 :doc:`../overview/architecture-memory`，理解 ``.com``/``.bank`` 和实时路径。
3. 根据开发板进入 :doc:`../middleware/board-adaptation`，确认管脚和资源配置。
4. 使用对应 HAL 页面完成一个外设闭环，再组合 UI 或 CBB。
5. 最后阅读 :doc:`../reference/index` 的验证、故障和发布要求。

非 MCU 内容
-----------

参考站点中的以下主题属于 Linux/Android 应用处理器开发，不适用于当前 MCU SDK，文档不会
照搬对应的软件栈：

* Linux 内核、设备树、Yocto/Buildroot 镜像构建：**不适用**。
* Android 应用 SDK、Framework、ADB/Fastboot：**不适用**。
* 多核异构处理器的 AVB、分区镜像和用户空间服务：**不适用**。

MCU 侧尚未形成稳定交付的通用 RTOS 适配层、量产烧录器和在线版本下载服务，已分别在
:doc:`../middleware/rtos-integration`、:doc:`../get-started/development-kit` 与
:doc:`../reference/release-delivery` 标记为 **待开发**。
