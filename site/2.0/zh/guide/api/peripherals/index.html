外设 HAL（片内外设）

本章按 platform/hal/api 中的公开 het_*.h 头文件组织。每个页面负责函数、参数、返回值、 回调事件和调用约束；场景说明、完整流程和测试代码见 HAL 外设 与 示例。

HAL 分层

  • platform/hal/api：应用和服务可引用的公开接口。

  • platform/hal/soc/bt8790：芯片相关实现，不应由应用直接调用。

  • 板级配置：负责实例、引脚、时钟和外设复用等产品差异。
