编译、下载与调试

编译

cd .\projects\watch320
python gen-srclist.py
make

固件位于 Output/bin/app.dcf。编译前检查 config.h，编译后保存工具链版本、Git 提交、 构建日志和固件校验值。

下载

当前工程输出目录包含 Downloader 工具。选择与目标板匹配的 app.dcf，关闭串口占用后下载， 复位并核对启动日志。串口下载参数、加密烧录和强制恢复手册 待开发。

调试

串口日志至少输出固件版本、板型、复位原因和关键初始化错误。BLE 无线终端、性能监控、一键日志 解析和自动化测试软件在说明书中属于规划能力，待开发。
