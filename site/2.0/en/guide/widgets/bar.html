Event interception and filtering

het_bar is a display control that does not register touch event callbacks and does not actively intercept MSG_CTP_*.

Component Description

het_bar is an LVGL-style progress bar component that supports three display semantics: basic progress, symmetric progress, and range progress, and is suitable for scenarios such as volume, power, buffer progress, and interval value display.

Create the bar component and mount it to the form page.

Parameters: frm target form; enable_anim whether to enable subsequent value switching animation capabilities.

Returns: void* component handle, returns NULL on failure.

Set the value range. It is recommended to set the range first and then set the current value.

Parameters: obj bar component handle; min minimum value; max maximum value, usually requiring min <= max.

void het_bar_set_mode(void *obj, const het_bar_mode mode)

void het_bar_set_value(void *obj, const int32_t value, const uint16_t duration)

Set the current value. duration=0 means immediate jump, non-0 means animation transition (unit: ms).

Usage example

void *bar = het_bar_create(frm, true);
het_bar_set_geometry(bar, HET_GEOMETRY(160, 120, 180, 16));
het_bar_set_range(bar, 0, 100);
het_bar_set_mode(bar, HET_BAR_MODE_NORMAL);
het_bar_set_style(bar, HET_BG_COLOR(80, 170, 255), HET_BG_COLOR(35, 40, 52));
het_bar_set_radius(bar, 8);

// 带动画更新到 65%
het_bar_set_value(bar, 65, 220);
