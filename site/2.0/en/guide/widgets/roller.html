Component Description

het_roller is used to scroll up and down in a limited candidate set, commonly used in date, time, enumeration configuration and other scenarios.

physical effects

Parameters and options

Listen for messages

filter conditions

result

MSG_CTP_TOUCH

The contact hits the roller background area

Hit: enter dragging and consume messages; miss: transparent transmission of messages

MSG_CTP_MOVE_*、MSG_CTP_LONG*、MSG_CTP_SHORT_*、MSG_CTP_CLICK、MSG_CTP_LONG_LIFT

dragging=true

Update displacement while dragging; activate inertia/adsorption when letting go; consume messages

Other news

If it is still dragging, the final release will also be executed.

Consume the message after finishing, otherwise the message will be transmitted transparently

Parameters and options

model

Semantics

Applicable scenarios

HET_ROLLER_PHYSICS_SNAP

No inertia, direct adsorption after letting go

Rigorous configuration page

HET_ROLLER_PHYSICS_INERTIA

Slide according to speed and then adsorb

Universal list scrolling

HET_ROLLER_PHYSICS_ELASTIC

Inertia + boundary damping/rebound

More natural touch

API introduction

void *het_roller_create(compo_form_t *frm, uint8_t visible_cnt)

Create a roller, specifying the number of visible rows.

Parameters: frm target form; visible_cnt visible row number, odd number is recommended.

Returns: void* roller component handle, returns NULL on failure.

void het_roller_set_geometry(void *obj, const rect_t rect)

Set the center coordinates, width and height, and the row height will be automatically calculated according to hei / visible_cnt.

Parameters: obj roller handle; rect geometry information.

void het_roller_set_options(void *obj, const char **opts, uint16_t opt_cnt)

Sets an array of options strings. Note that the string life cycle needs to cover the control life cycle.

Parameters: obj roller handle; opts option string array; opt_cnt option number.

void het_roller_set_selected(void *obj, uint16_t idx)

Select the specified item directly without animation.

Parameters: obj roller handle; idx target index, 0-based.

void het_roller_set_row_height(void *obj, int16_t row_h)

Set row height manually.

Parameters: obj roller handle; row_h height of each row.

void het_roller_set_color(void *obj, uint16_t bg_color, uint16_t sel_color, uint16_t text_color, uint16_t sel_text_color)

Set the background, selection bar, normal text, and selected text color.

Parameters: obj roller handle; bg_color background color; sel_color selected bar color; text_color normal text color; sel_text_color selected text color.

void het_roller_set_font(void *obj, uint32_t font)

To set the font, it is recommended to call set_options first.

Parameters: obj roller handle; font font resource ID.

void het_roller_set_radius(void *obj, uint16_t radius)

Sets the background corner radius.

Parameters: obj roller handle; radius fillet radius.

void het_roller_set_inf(void *obj, bool inf)

Turn on/off infinite loop scrolling.

Parameters: obj roller handle; inf whether to enable infinite loop.

void het_roller_set_physics(void *obj, const het_roller_physics_t *physics)

Set the physical effect, pass NULL to restore the default SNAP.

Parameters: obj roller handle; physics physical configuration pointer, restores the default configuration when it is NULL.

void het_roller_set_slot(void *obj, event_cb slot, void *user_data)

Register a callback, HET_EVENT_VALUE_CHANGED is triggered after the adsorption is completed and the value changes.

Parameters: obj roller handle; slot callback function; user_data user transparent transmission pointer.

void het_roller_set_visible(void *obj, bool visible)

Set visibility.

Parameters: obj roller handle; visible whether to display.

uint16_t het_roller_get_selected(const void *obj)

Get the currently selected index (0-based).

Parameters: obj roller handle.

Return: uint16_t index of the currently selected item.

const char *het_roller_get_selected_str(const void *obj)

Get the currently selected text.

Parameters: obj roller handle.

Return: const char* String pointer of the currently selected item.

Usage example

const het_roller_physics_t p = HET_ROLLER_PHYSICS_CONFIG(
    HET_ROLLER_PHYSICS_INERTIA,
    180,   // snap_ms
    3600,  // decel
    5,     // max_throw_rows
    96     // edge_resist
);
het_roller_set_physics(roller, &p);

static const char *days[] = {"一", "二", "三", "四", "五", "六", "日"};

void *roller = het_roller_create(frm, 5);
het_roller_set_geometry(roller, HET_GEOMETRY(160, 130, 92, 120));
het_roller_set_font(roller, UI_BUF_COFFEE_FONT_ARIAL_11_BIN);
het_roller_set_options(roller, days, 7);
het_roller_set_inf(roller, true);
het_roller_set_selected(roller, 2);
