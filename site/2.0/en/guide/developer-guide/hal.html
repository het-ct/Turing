HAL peripherals

Overview

platform/hal/api provides a unified interface for on-chip and on-chip peripherals. The application completes the peripheral life cycle through default configuration, initialization, transmission/control, callback and de-initialization. The specific pin reuse and instances are determined by the board-level configuration.

peripherals

Capability description

Key points of use and API

GPIO

Input, output, pull-up and pull-down, multiplexing and edge interrupt

Configure pin/mode/pull/irq_trigger; see GPIO general input and output (het_gpio.h)

ADC

10-bit analog sampling for battery, keys and temperature

Calibrate and select channels first; see ADC analog-to-digital conversion (het_adc.h)

DAC

Analog level and audio/wave output

Verify channel, range and DMA; see DAC digital-to-analog conversion (het_dac.h)

IIC

Sensor, EEPROM and touch controller bus

Check address width, speed and pull-up; see IIC bus (het_iic.h)

SPI

Flash, display and image sensor high-speed bus

Check mode, CS, DMA buffer and chip select timing; see SPI serial peripheral interface (het_spi.h)

UART

Ordinary serial port and HSUART DMA/flow control

The callback only delivers data; see UART asynchronous serial port (het_uart.h)

Timer

Cycles, counts, captures and system beats

ISR remains bounded; see Timer timer (het_timer.h)

PWM

Backlight, buzzer, motor and light effects

Frequency/mil duty cycle; see PWM pulse width modulation (het_pwm.h)

QDEC

Rotary encoder counts, directions and clicks

Check for 2/4 multiplier; see QDEC Quadrature Decoder (het_qdec.h)

LCD

8080, QSPI, SPI and RGB display transmission

Check package, Driver IC, TE and DMA; see LCD display controller (het_lcd.h)

How to use

  1. Contains het_api_hal.h or the target peripheral header file.

  2. Get het_*_def_cfg() and overwrite the necessary fields such as instance, pin, rate, etc.

  3. Call the initialization function and check the return value.

  4. Perform synchronous reads and writes or register asynchronous callbacks.

  5. Stop interrupts/DMA, unregister callbacks and deinitialize.

Example

#include "het_api_hal.h"

int led_init(het_gpio_id_t pin)
{
    het_gpio_handle_t cfg = het_gpio_def_cfg();
    cfg.pin = pin;
    cfg.mode = HET_GPIO_MODE_OUTPUT;
    cfg.default_level = 0;
    return het_gpio_init(&cfg);
}

Things to note

  • Avoid blocking, dynamic allocation and long logs in interrupt callbacks.

  • IIC/SPI device address, register width, and endianness should come from the device data sheet.

  • High-throughput interfaces such as LCD and audio require verification of DMA buffers and refresh timing.

  • SPI vs. UART Example：SPI Sync/DMA and UART DMA callbacks.
