Pin definition and reuse

Het-X1 is available in QFN32 and QFN68 packages, and the GPIO can be reused as UART, IIC, SPI, LCD, DVP, QDEC, PWM, ADC, USB control and debugging signals. The complete form is long and changes with the material number and board version. This page gives the usage rules.

Configuration steps

  1. Select the package and corresponding pin table according to the physical material number.

  2. Establish a “chip pin-board network-peripheral function-software macro” mapping table from the schematic diagram.

  3. Configure CHIP_PACKAGE_SELECT and PORT_* in projects/<project>/config.h.

  4. Check whether the display, touch, camera, Flash, audio and debugging ports compete for the same multiplexing group.

  5. After powering on, first verify the default levels, and then enable peripherals one by one.

S1 core board example

S1 leads out VBAT, VSYS, VDDIO, BOOT0, UART, PDM/I2S, IIC, LCD, touch, CAN, DVP, USB and RF signals. For detailed outline drawings, see the complete pin list of Packaging and development board。S2/S3 to be developed.

Warning

Do not use this page to manually create production PCB footprints, and do not copy PORT_* from other boards. Production designs must use controlled schematics, package libraries, and corresponding versions of pin mux tables.
