UI API

The UI API is divided into three layers: basic controls, layout/physical parameters and product forms:

  • Basic control: platform/middlewares/gui/components/include.

  • GUI runtime, screen and touch: platform/middlewares/gui.

  • Pages, menus and business forms: platform/services/UI/form.

For a list of controls and examples, see UI components。After the control is created, the life cycle is managed by the parent object or page.；Event callbacks should return quickly, animations and asynchronous sources must stop when the page exits。Component and form public headers have been included in Doxygen。

Form aggregation API see Service API；For an overview, usage and examples of each het control header file, see UI components。
