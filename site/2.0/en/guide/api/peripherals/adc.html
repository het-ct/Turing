ADC analog-to-digital conversion (het_adc.h)

Source file: platform/hal/api/het_adc.h

Overview

Het-X1 integrates a 10-bit, 16-channel SAR ADC, which can be used to collect analog quantities such as battery voltage, keys, and temperature, and supports DMA data transmission.

usage

Open the ADC using the default handle, enable the channel and read sample values ​​as needed; close the channel before exiting. Channels and pins are determined by board configuration.

Typical process

  1. Get the default configuration or prepare board-level configuration.

  2. Initialize the peripheral and check the return value.

  3. Perform read, write, control, or callback registration operations.

  4. Stop the asynchronous source and deinitialize the peripheral.

Example

#include "het_adc.h"

int adc_read_once(uint16_t *sample)
{
    het_adc_handle_t adc = het_adc_def_cfg();
    int ret = het_adc_open(&adc);
    if (ret != HET_OK) return ret;
    ret = het_adc_enable(&adc, 1);
    if (ret == HET_OK) ret = het_adc_read(&adc, sample);
    het_adc_enable(&adc, 0);
    het_adc_close(&adc);
    return ret;
}
