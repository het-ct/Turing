SPI serial peripheral interface (het_spi.h)

Source file: platform/hal/api/het_spi.h

Overview

Het-X1 provides SPI0/1/2, supporting master/slave mode, GPIO multiplexing and independent clock control; SPI2 can also serve display and image sensor data transmission.

usage

Configure frequency, clock polarity/phase, bit sequence, chip select and pin post-initialization. Select write, read or full-duplex transmission according to the device protocol. In asynchronous mode, a callback needs to be registered.

Typical process

  1. Get the default configuration or prepare board-level configuration.

  2. Initialize the peripheral and check the return value.

  3. Perform read, write, control, or callback registration operations.

  4. Stop the asynchronous source and deinitialize the peripheral.

Example

#include "het_spi.h"

int spi_exchange(het_spi_id_t id, const uint8_t *tx,
                 uint8_t *rx, uint16_t len)
{
    het_spi_config_t cfg = het_spi_def_cfg();
    int ret = het_spi_init(id, &cfg);
    if (ret != HET_OK) return ret;
    het_spi_cs_enable(id, 1);
    ret = het_spi_transfer(id, tx, rx, len);
    het_spi_cs_enable(id, 0);
    het_spi_deinit(id);
    return ret;
}

API introduction

Functions

het_spi_config_t het_spi_def_cfg(void)

获取 SPI 默认配置。

Returns:

默认配置：同步 DMA、软件片选、单线模式。

int het_spi_init(het_spi_id_t id, const het_spi_config_t *config)

初始化 SPI 实例。

Parameters:

  • id – [in] SPI 实例 ID。BT8790 目前仅支持 HET_SPI_ID_1。

  • config – [in] SPI 配置。

Returns:

HET_OK 表示成功，否则返回 HET_ERR_* 值。

int het_spi_deinit(het_spi_id_t id)

反初始化 SPI 实例。

Parameters:

  • id – [in] SPI 实例 ID。

Returns:

HET_OK 表示成功，否则返回 HET_ERR_* 值。

int het_spi_cs_enable(het_spi_id_t id, uint8_t en)

控制软件片选。

Parameters:

  • id – [in] SPI 实例 ID。

  • en – [in] 1 选中设备，0 释放设备。

Returns:

HET_OK 表示成功，否则返回 HET_ERR_* 值。

int het_spi_write(het_spi_id_t id, const uint8_t *data, uint16_t len)

通过 DMA 写入数据。

Parameters:

  • id – [in] SPI 实例 ID。

  • data – [in] 发送缓冲区。

  • len – [in] 发送字节数。

Returns:

HET_OK 表示成功，否则返回 HET_ERR_* 值。

int het_spi_read(het_spi_id_t id, uint8_t *data, uint16_t len)

通过 DMA 读取数据。

Parameters:

  • id – [in] SPI 实例 ID。

  • data – [out] 接收缓冲区。

  • len – [in] 接收字节数。

Returns:

HET_OK 表示成功，否则返回 HET_ERR_* 值。

int het_spi_transfer(het_spi_id_t id, const uint8_t *tx_data, uint8_t *rx_data, uint16_t len)

执行 SPI 传输。完整的发送+接收传输实现为先写后读。

Parameters:

  • id – [in] SPI 实例 ID。

  • tx_data – [in] 发送缓冲区，或仅读时传 NULL。

  • rx_data – [out] 接收缓冲区，或仅写时传 NULL。

  • len – [in] 字节数。

Returns:

HET_OK 表示成功，否则返回 HET_ERR_* 值。

int het_spi_register_cb(het_spi_id_t id, het_spi_cb_t cb, void *user_ctx)

注册异步传输回调。

Parameters:

  • id – [in] SPI 实例 ID。

  • cb – [in] 从 SPI ISR 调用的回调。

  • user_ctx – [in] 回传给 cb 的用户上下文。

Returns:

HET_OK 表示成功，否则返回 HET_ERR_* 值。

int het_spi_unregister_cb(het_spi_id_t id)

注销异步传输回调。

Parameters:

  • id – [in] SPI 实例 ID。

Returns:

HET_OK 表示成功，否则返回 HET_ERR_* 值。
