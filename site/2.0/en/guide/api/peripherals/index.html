Peripheral HAL (on-chip and on-chip peripherals)

This chapter is organized by the public het_*.h header files in platform/hal/api. Each page is responsible for functions, parameters, return values, callback events and calling constraints; for scenario description, complete process and test code, see HAL peripherals and Example。

HAL layering

  • platform/hal/api: A public interface that applications and services can reference.

  • platform/hal/soc/bt8790: Chip-related implementation, should not be called directly by applications.

  • Board level configuration: Responsible for product differences such as instances, pins, clocks, and peripheral multiplexing.
