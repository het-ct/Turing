Timer timer (het_timer.h)

Source file: platform/hal/api/het_timer.h

Overview

Het-X1 provides 6 32-bit timers. Timer0~2 supports timing/counting, and Timer3~5 also supports capture and PWM, and provides multiple clock sources and prescalers.

usage

Select a timer instance, set the period and register callbacks as needed. After starting, the count can be read or the period can be dynamically adjusted; after stopping the timer, the callback and de-initialization can be logged off.

Typical process

  1. Get the default configuration or prepare board-level configuration.

  2. Initialize the peripheral and check the return value.

  3. Perform read, write, control, or callback registration operations.

  4. Stop the asynchronous source and deinitialize the peripheral.

Example

#include "het_timer.h"

int timer_start_periodic(het_timer_id_t id, uint32_t period_us)
{
    het_timer_config_t cfg = het_timer_def_cfg();
    int ret = het_timer_init(id, &cfg);
    if (ret != HET_OK) return ret;
    if ((ret = het_timer_set_period(id, period_us)) != HET_OK) return ret;
    return het_timer_start(id);
}

API introduction

Functions

het_timer_config_t het_timer_def_cfg(void)

获取定时器默认配置。

Returns:

默认配置：周期模式、1000us 周期。

int het_timer_init(het_timer_id_t id, const het_timer_config_t *config)

使用配置参数初始化定时器。

Note

周期或单次模式下可通知定时器事件。

Parameters:

  • id – [in] TIMER 实例 id，例如 HET_TIMER_ID_0。

  • config – [in] 周期、定时器模式。

Returns:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_timer_deinit(het_timer_id_t id)

反初始化定时器。

Parameters:

  • id – [in] TIMER 实例 id。

Returns:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_timer_start(het_timer_id_t id)

启动定时器。

Note

触发 HET_TIMER_EVENT_PERIOD 或 HET_TIMER_EVENT_ONESHOT。

Parameters:

  • id – [in] TIMER 实例 id。

Returns:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_timer_stop(het_timer_id_t id)

停止定时器。

Parameters:

  • id – [in] TIMER 实例 id。

Returns:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_timer_set_period(het_timer_id_t id, uint32_t period_us)

设置定时器周期，用于运行中调节的场景。

Parameters:

  • id – [in] TIMER 实例 id。

  • period_us – [in] 周期，单位 us。

Returns:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_timer_get_count(het_timer_id_t id, uint32_t *count)

获取当前计数值。

Parameters:

  • id – [in] TIMER 实例 id。

  • count – [out] 计数值输出指针。

Returns:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_timer_register_cb(het_timer_id_t id, het_timer_cb_t cb, void *user_ctx)

注册定时器事件回调。

Note

见 TIMER 事件。

Parameters:

  • id – [in] TIMER 实例 id。

  • cb – [in] 回调函数。

  • user_ctx – [in] 用户上下文。

Returns:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_timer_unregister_cb(het_timer_id_t id)

注销定时器事件回调。

Parameters:

  • id – [in] TIMER 实例 id。

Returns:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。
