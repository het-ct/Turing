IIC bus (het_iic.h)

Source file: platform/hal/api/het_iic.h

Overview

Het-X1 provides 3 groups of IIC controllers, supports host/slave mode, and SCL/SDA can be mapped to multiple groups of GPIO, suitable for connecting sensors, EEPROM and touch controllers.

usage

Determine the controller, pins, and speed through board-level configuration. After initialization, read and write are performed according to the device address, register address and address width, and de-initialization is completed at the end.

Typical process

  1. Get the default configuration or prepare board-level configuration.

  2. Initialize the peripheral and check the return value.

  3. Perform read, write, control, or callback registration operations.

  4. Stop the asynchronous source and deinitialize the peripheral.

Example

#include "het_iic.h"

int iic_read_register(het_iic_id_t id, uint8_t addr,
                      uint16_t reg, uint8_t *data, uint16_t len)
{
    het_iic_handle_t iic = het_iic_def_cfg();
    int ret = het_iic_init(&iic);
    if (ret != HET_OK) return ret;
    ret = het_iic_read(id, addr, reg, 1, data, len);
    het_iic_deinit(id);
    return ret;
}
