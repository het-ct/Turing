低功耗与电源管理
================

概述
----

Het-X1 集成 LDO、锂电充电管理和 NVDC，工程还提供 ``platform/bsp/bsp_sleep.c``、
``bsp_charge.c`` 等板级实现。低功耗必须联合处理时钟、显示、触摸、无线、存储和唤醒源。

配置项
------

``config.h`` 中与功耗相关的配置包括 ``BUCK_MODE_EN``、``SYS_CLK_SEL``、
``SOFT_POWER_ON_OFF``、``LP_XOSC_CLOCK_EN``、``RTC_CLOCK_PDN_EN`` 和
``GUI_AUTO_POWER_EN``。不同板卡支持范围可能不同，修改后必须实测电流。

进入低功耗流程
--------------

1. 应用停止新业务并等待存储、音频、显示和通信操作完成。
2. 保存必要状态，关闭背光和不需要的外设中断/DMA。
3. 配置按键、RTC、触摸或通信唤醒源。
4. 调用板级休眠入口。
5. 唤醒后恢复时钟、总线、显示和服务，并检查唤醒原因。

示例
----

.. code-block:: c

   int app_enter_sleep(void)
   {
       ui_suspend();
       storage_flush();
       bsp_sleep_prepare();
       return bsp_sleep_enter();
   }

注意事项
--------

* 进入休眠前必须完成 Flash 写入，禁止在掉电窗口更新关键配置。
* RTC 和低功耗晶振选择会影响关机电流与计时精度。
* 唤醒后不能假设所有外设寄存器仍保持原值。
* 各模式的典型/最大电流、允许唤醒源和恢复时延 **待开发**。

主要 API
--------

当前以 ``bsp_sleep.h``、``bsp_charge.h`` 和工程电源控制函数为准；统一电源管理 API **待开发**。
