FAQ

Compiler or make not found

Run the toolchain version commands, make --version and python --version in a new terminal. Check PATH and then reopen the terminal. For detailed steps, see Environment setup。

Compilation successful but no app.dcf

Confirm it is in the target project directory and check the first compilation error. Normal output is projects/<project>/Output/bin/app.dcf. Re-execute python gen-srclist.py and check the function switches and inclist.mk.

The downloader cannot find the serial port

Close the serial port assistant, re-plug and unplug the development board, and confirm the driver and COM port in the device manager. The specific driver model and download parameters are to be developed.

Peripheral initialization failed

Document return values, peripheral instances, pin multiplexing, clocks, power supplies, addresses, and initialization sequences. First run the minimal example in Example, and then connect to the BSP and business.

Display is normal but no response to touch

Verify touch power, reset, interrupt, IIC address and original coordinates respectively to confirm that there is no multiplexing conflict between display and touch; check coordinate conversion synchronously after screen rotation.

Unable to start after upgrade

Keep the upgrade log and check the target partition, firmware integrity, signature, board version and image confirmation status. Stop repeatedly overwriting the bootable partition and restore it according to the abnormal path of OTA upgrade. Mass production forced recovery process to be developed.
