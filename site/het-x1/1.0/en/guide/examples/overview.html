How to run the example

platform/examples/example.c is assigned to a specific example by test number, and USE_EXAMPLES in example_api.h controls whether the example is compiled. The current table has connected SPI, LCD, hardware timer, QDEC, audio playback and cup body anti-dry burning protocol examples; GPIO, IIC, UART, PWM and other files can be directly called from the project entrance.

Usage steps

  1. Set USE_EXAMPLES to 1 in platform/examples/example_api.h.

  2. Confirm that the target example has been added to test_func_table, or call its entry point explicitly from product engineering.

  3. Modify the instance, pins, frequency, device address and resources to match the target board.

  4. Rerun gen-srclist.py and compile.

  5. Go to the board to observe the serial port logs and peripheral waveforms, and restore the example switch after the test is completed.

Warning

Some tests include infinite loops, busy waiting or fixed test pins, which are only used for laboratory verification and cannot directly enter the product main loop.
