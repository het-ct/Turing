IIC Peripheral Example

Source file: platform/examples/hal/example_iic.c. The example initializes IIC1, selects the PA8/PA9 multiplexing group, and accesses the device register at address 0x14. This address and register are from the original test device and cannot be used directly for other sensors.

het_iic_handle_t iic = het_iic_def_cfg();
iic.id = HET_IIC_ID_1;
iic.port_map = HET_IIC1_G2_PA8_PA9;
int ret = het_iic_init(&iic);
if (ret < 0) return ret;

uint8_t value = 0;
return het_iic_read(HET_IIC_ID_1, 0x14, 0x814E, 2, &value, 1);

Verification confirms 7-bit/8-bit address conventions, register widths, pull-up resistors, and power supplies. API see IIC bus (het_iic.h)。
