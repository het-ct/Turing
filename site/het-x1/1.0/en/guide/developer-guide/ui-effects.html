UI special effects

Overview

UI special effects include visual behaviors such as inertia/rebound, page switching, rotation, cube, honeycomb layout, transparency and blur. They rely on GPU, PSRAM, refresh bandwidth, and touch sampling, and must control resource budgets based on the target resolution.

Special effects topic

Instructions 2.3.1.10 to 2.3.1.17 correspond to the following advanced views:

  • ListView: horizontal/vertical list, touch and click event consumption.

  • DiskView: Disc list and rotation selection.

  • RotaryView: Rotary menu and rotating navigation.

  • HoneycombView: Honeycomb arrangement and selection events.

  • BallView: Ball view, current example video and stable API to be developed.

  • CubeView: Cube rotation animation, dependent on GPU/buffer resources, to be developed.

  • MapsView: map views, data sources and zoom strategies to be developed.

  • CurveView: Curve view, sampling, zooming and refreshing interface to be developed.

The main event interfaces of ListView, DiskView, RotaryView and HoneycombView are het_menu_hori/vert_event, het_form_disk_menu_event, het_form_rotary_menu_event and het_form_honeycomb_menu_event respectively; the parameters are subject to the corresponding form header file.

Configuration process

  1. Confirm GUI_SELECT, resolution, number of refresh lines and PSRAM configuration at config.h.

  2. First use a static page to verify display and touch, and then enable a single special effect.

  3. Adjust animation time, deceleration and boundary damping, and record the worst frame time.

  4. Check whether objects and buffers are leaked after page switching, pop-up windows and low-power wake-up.

Example

het_physics_t physics = HET_PHYSICS_CONFIG(
    HET_PHYSICS_INERTIA, 180, 3600, 96);
het_roller_set_physics(roller, &physics);

Things to note

Gaussian blur, full screen rotation, and high resolution double buffering may require PSRAM. Do not enable all effects at the same time and then locate the lag. Measure the CPU/GPU, memory and refresh cycle one by one. Physical parameters such as inertia, deceleration, and boundary rebound should be adjusted from a small range, and the worst frame time at the target resolution should be recorded.

Main API

Physics, rotation and component effects header files are located in platform/middlewares/gui; full stable API list to be developed.
