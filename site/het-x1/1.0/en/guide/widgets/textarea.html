Component Description

het_textarea aligns LVGL lv_textarea semantics, supports multi-line/single-line input, cursor positioning and blinking, placeholders, password masks, text addition, deletion and modification, etc.

API introduction

void * het_textarea_create(compo_form_t *frm)

Create textarea component.

Parameters: frm target form.

Returns: void* textarea component handle, returns NULL on failure.

void het_textarea_set_geometry(void *obj, const rect_t rect)

Set position and size.

Parameters: obj textarea handle; rect geometry information.

void het_textarea_set_font(void *obj, const uint32_t font)

Set the font. It is recommended to call it first after creation.

Parameters: obj textarea handle; font font resource ID.

void het_textarea_set_text(void *obj, const char *txt)

Overwrite the entire text and move the cursor to the end.

Parameters: obj textarea handle; txt new text content.

void het_textarea_add_text(void *obj, const char *txt)

Appends a string (UTF-8) at the cursor.

Parameters: obj textarea handle; txt string to be appended.

void het_textarea_add_char(void *obj, const char c)

Appends a single ASCII character at the cursor.

Parameters: obj textarea handle; c The character to be appended.

void het_textarea_del_char(void *obj)

Delete one UTF-8 character (backspace) to the left of the cursor.

Parameters: obj textarea handle.

void het_textarea_del_char_forward(void *obj)

Delete the UTF-8 character to the right of the cursor (Delete).

Parameters: obj textarea handle.

void het_textarea_clear_text(void *obj)

Clears all text and returns the cursor to zero.

Parameters: obj textarea handle.

void het_textarea_set_placeholder(void *obj, const char *txt, const uint32_t font, const uint16_t color)

Set placeholder text, font and color.

Parameters: obj textarea handle; txt placeholder text; font placeholder font; color placeholder color.

void het_textarea_set_password_mode(void *obj, const bool en)

When enabled, the text is displayed with a * mask.

Parameters: obj textarea handle; en whether to enable password mode.

void het_textarea_set_one_line(void *obj, const bool en)

Enter input is ignored when single-line mode is enabled.

Parameters: obj textarea handle; en whether to enable single-line mode.

void het_textarea_set_text_color(void *obj, const uint16_t color)

Set text color.

Parameters: obj textarea handle; color text color (RGB565).

void het_textarea_set_bg_color(void *obj, const het_bg_res_t style)

Set the background style (solid color or background resource).

Parameters: obj textarea handle; style background style resource.

void het_textarea_set_bg_radius(void *obj, const uint16_t radius)

Set the input box background to have rounded corners.

Parameters: obj textarea handle; radius corner radius (pixels).

void het_textarea_set_padding(void *obj, const het_pad_t padding)

Set padding (the space between text and background edges).

Parameters: obj textarea handle; padding padding parameter.

void het_textarea_set_visible(void *obj, const bool visible)

Set control visibility.

Parameters: obj textarea handle; visible is true to display, false to hide.

void het_textarea_set_cursor_pos(void *obj, const uint16_t pos)

Sets the cursor byte offset (auto-aligned to UTF-8 boundaries).

Parameters: obj textarea handle; pos target cursor byte position.

void het_textarea_set_cursor_end(void *obj)

Move the cursor to the end of the text.

Parameters: obj textarea handle.

void het_textarea_set_cursor_begin(void *obj)

Move the cursor to the beginning of the text.

Parameters: obj textarea handle.

void het_textarea_set_cursor_style(void *obj, const uint16_t width, const uint16_t height, const uint16_t color)

Set cursor style.

Parameters: obj textarea handle; width/height cursor size; color cursor color.

void het_textarea_set_cursor_blink_time(void *obj, const uint16_t ms)

Set the cursor to flash for half a period, 0 means always on.

Parameters: obj textarea handle; ms cursor flashing half cycle, unit ms.

void het_textarea_set_slot(void *obj, event_cb cb, void *user_data)

Register callback, support HET_EVENT_VALUE_CHANGED / HET_EVENT_CLICKED.

Parameters: obj textarea handle; cb callback function; user_data user transparent transmission pointer.

const char * het_textarea_get_text(const void *obj)

Get the current text read-only pointer.

Parameters: obj textarea handle.

Return: const char* read-only pointer of the current text buffer.

uint16_t het_textarea_get_text_len(const void *obj)

Get the text length in bytes.

Parameters: obj textarea handle.

Return: uint16_t current text length in bytes.

uint16_t het_textarea_get_cursor_pos(const void *obj)

Get the current cursor position.

Parameters: obj textarea handle.

Return: uint16_t current cursor byte offset.

Usage example

void *ta = het_textarea_create(frm);
het_textarea_set_geometry(ta, HET_GEOMETRY(160, 120, 220, 76));
het_textarea_set_font(ta, UI_BUF_COFFEE_FONT_ARIAL_11_BIN);
het_textarea_set_bg_color(ta, HET_BG_COLOR(32, 38, 52));
het_textarea_set_text_color(ta, COLOR_WHITE);
het_textarea_set_placeholder(ta, "请输入设备名称", UI_BUF_COFFEE_FONT_ARIAL_11_BIN, make_color(145, 156, 178));
het_textarea_set_one_line(ta, true);
het_textarea_set_cursor_blink_time(ta, 350);
