QDEC Quadrature Decoder (het_qdec.h)

Source file: platform/hal/api/het_qdec.h

Overview

Het-X1 integrates a 1-channel quadrature decoder that can read the count and direction of the rotary encoder, suitable for knob, roller and position detection.

usage

After obtaining the default configuration and initializing the instance, start counting, and read the count value and direction periodically. When using the callback, register it first and then deinitialize it after stopping.

Typical process

  1. Get the default configuration or prepare board-level configuration.

  2. Initialize the peripheral and check the return value.

  3. Perform read, write, control, or callback registration operations.

  4. Stop the asynchronous source and deinitialize the peripheral.

Example

#include "het_qdec.h"

int qdec_read_count(het_qdec_id_t id, int32_t *count)
{
    het_qdec_config_t cfg = het_qdec_def_cfg();
    int ret = het_qdec_init(id, &cfg);
    if (ret != HET_OK) return ret;
    if ((ret = het_qdec_start(id)) == HET_OK)
        ret = het_qdec_get_count(id, count);
    het_qdec_stop(id);
    het_qdec_deinit(id);
    return ret;
}

API introduction

Functions

het_qdec_config_t het_qdec_def_cfg(void)

获取正交编码器默认配置。

Returns:

默认配置：硬件模式、滤波长度 4、软件扫描周期 1 ms，输入为 PA0 和 PA1。

int het_qdec_init(het_qdec_id_t id, const het_qdec_config_t *config)

初始化正交编码器实例。

Parameters:

  • id – [in] 编码器实例 ID；硬件模式仅支持 HET_QDEC_ID_HW。

  • config – [in] 编码器配置，不可为 NULL。

Returns:

HET_OK 表示成功，否则返回 HET_ERR_* 错误码。

int het_qdec_deinit(het_qdec_id_t id)

反初始化正交编码器实例并释放相关资源。

Parameters:

  • id – [in] 编码器实例 ID。

Returns:

HET_OK 表示成功，否则返回 HET_ERR_* 错误码。

int het_qdec_start(het_qdec_id_t id)

启动正交编码器计数和事件检测。

Parameters:

  • id – [in] 编码器实例 ID。

Returns:

HET_OK 表示成功，否则返回 HET_ERR_* 错误码。

int het_qdec_stop(het_qdec_id_t id)

停止正交编码器计数和事件检测。

Parameters:

  • id – [in] 编码器实例 ID。

Returns:

HET_OK 表示成功，否则返回 HET_ERR_* 错误码。

int het_qdec_get_count(het_qdec_id_t id, int32_t *count)

获取编码器累计计数值。

Parameters:

  • id – [in] 编码器实例 ID。

  • count – [out] 累计计数值输出指针；正向事件加一，反向事件减一。

Returns:

HET_OK 表示成功，否则返回 HET_ERR_* 错误码。

int het_qdec_get_direction(het_qdec_id_t id, het_qdec_direction_t *direction)

获取编码器最近一次运动方向。

Parameters:

  • id – [in] 编码器实例 ID。

  • direction – [out] 运动方向输出指针。

Returns:

HET_OK 表示成功，否则返回 HET_ERR_* 错误码。

int het_qdec_clear_count(het_qdec_id_t id)

清零累计计数，并将运动方向重置为静止。

Parameters:

  • id – [in] 编码器实例 ID。

Returns:

HET_OK 表示成功，否则返回 HET_ERR_* 错误码。

int het_qdec_register_cb(het_qdec_id_t id, het_qdec_cb_t cb, void *user_ctx)

注册编码器转动事件回调。

Note

硬件模式下回调可能在中断上下文中执行。

Parameters:

  • id – [in] 编码器实例 ID。

  • cb – [in] 事件回调函数，不可为 NULL。

  • user_ctx – [in] 用户上下文，触发事件时原样传给回调函数。

Returns:

HET_OK 表示成功，否则返回 HET_ERR_* 错误码。

int het_qdec_unregister_cb(het_qdec_id_t id)

注销编码器转动事件回调。

Parameters:

  • id – [in] 编码器实例 ID。

Returns:

HET_OK 表示成功，否则返回 HET_ERR_* 错误码。

void het_qdec_process(void)

对编码器的两个输入引脚执行一次采样和软件解码。

Note

仅软件模式需要调用，建议按配置项 scan_ms 指定的周期调用。 实例无效、未初始化、未启动或处于硬件模式时，本函数不执行操作。
