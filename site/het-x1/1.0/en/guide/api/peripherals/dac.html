DAC digital-to-analog conversion (het_dac.h)

Source file: platform/hal/api/het_dac.h

Overview

DACs are designed to output programmable analog levels or continuously sampled data, serving audio, waveform, and analog control scenarios. Actual channels, accuracy, and output range are subject to board-level implementation.

usage

Initialize the specified DAC instance after obtaining the default configuration, write the output data through single point writing or buffer, and deinitialize after completion.

Typical process

  1. Get the default configuration or prepare board-level configuration.

  2. Initialize the peripheral and check the return value.

  3. Perform read, write, control, or callback registration operations.

  4. Stop the asynchronous source and deinitialize the peripheral.

Example

#include "het_dac.h"

int dac_write_value(het_dac_id_t id, uint8_t channel, uint32_t value)
{
    het_dac_config_t cfg = het_dac_def_cfg();
    int ret = het_dac_init(id, &cfg);
    if (ret != HET_OK) return ret;
    ret = het_dac_write(id, channel, value);
    het_dac_deinit(id);
    return ret;
}

API introduction

Functions

het_dac_config_t het_dac_def_cfg(void)

获取 DAC 默认配置。

Returns:

默认配置：12 位分辨率、内部参考、轮询模式。

int het_dac_init(het_dac_id_t id, const het_dac_config_t *config)

初始化 DAC 实例。

Parameters:

  • id – [in] DAC 实例 ID，例如 HET_DAC_ID_0。

  • config – [in] DAC 配置参数（分辨率、参考电压、传输模式）。

Returns:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_dac_deinit(het_dac_id_t id)

反初始化 DAC 实例。

Parameters:

  • id – [in] DAC 实例 ID。

Returns:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_dac_write(het_dac_id_t id, uint8_t channel, uint32_t value)

按初始化传输模式输出单通道原始 DAC 值。

Note

DMA 模式下通知 HET_DAC_EVENT_DONE、HET_DAC_EVENT_ERROR。

Parameters:

  • id – [in] DAC 实例 ID。

  • channel – [in] DAC 通道号。

  • value – [in] 原始输出值。

Returns:

ret > 0 成功或已启动；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_dac_write_buffer(het_dac_id_t id, uint8_t channel, const uint16_t *data, uint16_t len)

按初始化传输模式输出波形缓冲区。

Note

DMA 模式下通知 HET_DAC_EVENT_DONE、HET_DAC_EVENT_ERROR。

Parameters:

  • id – [in] DAC 实例 ID。

  • channel – [in] DAC 通道号。

  • data – [in] 波形数据缓冲区。

  • len – [in] 数据长度。

Returns:

ret > 0 成功或已启动；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_dac_register_cb(het_dac_id_t id, het_dac_cb_t cb, void *user_ctx)

注册 DAC 事件回调。

Parameters:

  • id – [in] DAC 实例 ID。

  • cb – [in] 回调函数。

  • user_ctx – [in] 用户上下文。

Returns:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_dac_unregister_cb(het_dac_id_t id)

注销 DAC 事件回调。

Parameters:

  • id – [in] DAC 实例 ID。

Returns:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。
