USB 通讯库
==========

.. container:: module-summary cbb-summary

   **CBB 能力组件**

   对应 USB Host / Device 及常见类能力。

概述
----

本模块面向 **USB 设备与主机通信**。该页面建议补充 MSC、UVC、UAC、CID、HID 等类驱动的业务封装与枚举流程。

核心能力
--------

.. container:: capability-list

   * **USB Host**：说明 Mass Storage、UVC 等主机模式能力。
   * **USB Device**：说明 MSC、UVC、UAC、HID 等设备模式能力。
   * **类驱动接口**：说明类驱动初始化、状态回调和数据交互方式。

使用方法
--------

配置描述符和端点，启动 USB 协议栈，并在事件循环中处理枚举、收发和断开。

#. 准备依赖的 HAL、板级资源和任务/中断上下文。
#. 创建配置并注册状态、数据或错误回调。
#. 启动组件，将输入数据或系统事件送入处理接口。
#. 在业务循环中消费输出，并处理超时、断连和资源不足。
#. 停止数据源，等待异步操作结束，再释放组件资源。

使用示例
--------

以下代码展示应用适配层的接入骨架。函数名用于说明职责，应替换为项目中实际提供的 CBB 接口。

.. code-block:: c

   static void app_usb_event(const void *event)
   {
       /* 将状态或处理结果投递到产品业务层。 */
       (void)event;
   }

   int app_usb_start(void)
   {
       int ret = board_usb_prepare();
       if (ret != 0) return ret;

       ret = product_usb_init(app_usb_event);
       if (ret != 0) return ret;
       return product_usb_start();
   }

   int app_usb_process(const void *usb_event)
   {
       if (usb_event == NULL) return -1;
       return product_usb_process(usb_event);
   }

API 说明
--------

当前 CBB 页面尚未关联稳定的公开头文件。建议由具体实现提供以下适配层职责，并在公开头文件落地后改为 Doxygen 自动接口说明。

.. list-table:: 建议适配层接口
   :header-rows: 1
   :widths: 28 45 27

   * - 接口职责
     - 说明
     - 调用约束
   * - ``init(config, callback)``
     - 校验配置、创建上下文并注册事件回调。
     - 每个实例只初始化一次。
   * - ``start()``
     - 启动数据源、协议状态机或算法任务。
     - 必须在初始化成功后调用。
   * - ``process(input)``
     - 输入数据帧或系统事件并产生结果。
     - 明确线程、中断和缓冲区所有权。
   * - ``set_callback(callback)``
     - 注册状态、数据和错误通知。
     - 回调中避免阻塞操作。
   * - ``stop() / deinit()``
     - 停止异步来源并释放资源。
     - 先停止，再销毁上下文。

注意事项
--------

* 对实时数据链路明确采样周期、最大延迟和缓冲深度。
* 错误码应保留底层原因，并由产品层决定重试、降级或复位策略。
* 回调、DMA 和任务仍在运行时，不得释放配置、缓冲区或用户上下文。
* CBB 与 HAL 的依赖关系应集中在适配层，避免业务代码直接访问芯片实现。
