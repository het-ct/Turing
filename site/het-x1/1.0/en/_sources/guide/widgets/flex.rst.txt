组件说明
--------

het_flex 是轻量级线性布局容器，用于在主轴方向（行/列）上排列子项，并支持主轴分配与交叉轴对齐。

* 适用于同类型控件的规则排列，如按钮组、信息条、状态块。

* 每个子项可设置固定尺寸、百分比尺寸或自动尺寸。

* 通过 grow 可在剩余空间内进行弹性扩展。

参数与选项
----------

.. list-table::
   :header-rows: 1

   * - 宏
     - 值/原型
     - 说明
   * - HET_FLEX_MAX_ITEMS
     - 4（可重定义）
     - 容器可容纳的最大子项数量。
   * - HET_FLEX_SIZE_AUTO
     - -1
     - 自动尺寸标记。
   * - HET_FLEX_PCT_BASE
     - 1000
     - 百分比基数。
   * - HET_FLEX_PCT(pct)
     - ((int16_t)(-1000 - (pct)))
     - 将百分比尺寸编码为内部尺寸值。

参数与选项
----------

.. list-table::
   :header-rows: 1

   * - 枚举值
     - 说明
   * - HET_FLEX_DIR_ROW
     - 主轴为水平方向（从左到右）。
   * - HET_FLEX_DIR_COLUMN
     - 主轴为垂直方向（从上到下）。

参数与选项
----------

.. list-table::
   :header-rows: 1

   * - 枚举值
     - 说明
   * - HET_FLEX_JUSTIFY_START
     - 子项从主轴起点开始排列。
   * - HET_FLEX_JUSTIFY_CENTER
     - 子项在主轴方向居中排列。
   * - HET_FLEX_JUSTIFY_END
     - 子项靠主轴终点排列。
   * - HET_FLEX_JUSTIFY_SPACE_BETWEEN
     - 首尾贴边，剩余空间均分到相邻子项间隙。

参数与选项
----------

.. list-table::
   :header-rows: 1

   * - 枚举值
     - 说明
   * - HET_FLEX_ALIGN_START
     - 子项在交叉轴起点对齐。
   * - HET_FLEX_ALIGN_CENTER
     - 子项在交叉轴居中对齐。
   * - HET_FLEX_ALIGN_END
     - 子项在交叉轴终点对齐。
   * - HET_FLEX_ALIGN_STRETCH
     - 子项在交叉轴方向拉伸填充。

使用示例
--------

.. code-block:: c

   void *flex = het_flex_create(frm);
   het_flex_set_geometry(flex, HET_GEOMETRY(160, 120, 220, 72));
   het_flex_set_padding(flex, HET_PADDING(6, 8, 8, 6));
   het_flex_set_gap(flex, 8);
   het_flex_set_flow(flex,
                     HET_FLEX_DIR_ROW,
                     HET_FLEX_JUSTIFY_SPACE_BETWEEN,
                     HET_FLEX_ALIGN_CENTER);
   
   void *btn_ok = het_button_create(frm->page, HET_BG_MODE_SC, 7);
   void *btn_cancel = het_button_create(frm->page, HET_BG_MODE_SC, 7);
   
   het_flex_add_pct(flex, btn_ok, 45, 100, 0);
   het_flex_add_pct(flex, btn_cancel, 45, 100, 0);
   het_flex_update(flex);
