VS Code 与插件

VS Code 用于项目浏览、源码编辑、Git、终端和插件集成。安装流程见 环境搭建。

建议插件

  • C/C++：代码导航和基础诊断。

  • PlatformIO IDE：串口终端等辅助能力，不替代工程自身的 Make 构建。

  • PlantUML：维护架构图和流程图。

  • HeT Plugin：项目配置、代码模板和 API 帮助；当前离线安装包与稳定功能范围以交付版本为准。

说明书中规划的新建 Task、定时器、HAL、CBB、GUI 页面、自动切图、性能监控和自动测试等能力 尚未全部在仓库形成可验证插件功能，未验证部分均为 待开发。
