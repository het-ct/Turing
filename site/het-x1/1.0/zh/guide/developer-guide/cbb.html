CBB 能力组件

概述

CBB 将算法、通信或系统能力封装为可复用组件。组件应暴露明确配置、输入事件、输出事件和生命周期， 不得隐式占用板级资源。

组件目录

现有专题包括音频算法、蓝牙通信、CANopen、IMU、红外、充电、日志、Modbus、电机、RGB 灯、 安全存储、USB、视觉和 Wi-Fi，入口见 CBB 能力组件。每个专题页面都应说明依赖、初始化、 输入/输出、错误恢复和示例；仓库中没有 het 前缀稳定头文件的能力保持 待开发。

使用方法

  1. 在组件页面确认依赖的 HAL、BSP、中间件和内存预算。

  2. 在板级配置中分配总线、DMA、任务和缓冲区。

  3. 初始化后注册事件回调，由任务周期处理输入。

  4. 对断连、超时、数据损坏和资源不足设计恢复路径。

  5. 停止组件后释放回调、任务和外设资源。

示例

int app_component_start(void)
{
    cbb_config_t cfg = cbb_default_config();
    cfg.event_cb = app_on_cbb_event;
    return cbb_init(&cfg); /* 通用接口形式，具体名称以组件头文件为准。 */
}

主要 API

音频、视觉、IMU、电机、蓝牙、Wi-Fi、USB、红外、Modbus、CANopen、灯效、充电、日志和安全 存储的专题见 CBB 能力组件。未在仓库提供稳定头文件的组件仍标记为待开发。
