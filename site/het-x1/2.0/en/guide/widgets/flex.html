het_flex flexible layout container

UI components

include/het_flex.h

include/het_flex.h

Component Description

het_flex is a lightweight linear layout container used to arrange children in the main axis direction (row/column), and supports main axis allocation and cross-axis alignment.

  • Suitable for regular arrangement of controls of the same type, such as button groups, information bars, and status blocks.

  • Each subitem can be set to a fixed size, percentage size, or automatic size.

  • Grow can be used to flexibly expand within the remaining space.

The children are arranged starting from the starting point of the main axis.

The children are centered along the main axis.

HET_FLEX_JUSTIFY_END

The children are arranged by the end point of the main axis.

HET_FLEX_JUSTIFY_SPACE_BETWEEN

The beginning and end are welted, and the remaining space is evenly divided into the gaps between adjacent items.

API introduction

void *het_flex_create(compo_form_t *frm)

Create a flex container object.

Parameters: frm target form.

Returns: void* container handle, returns NULL on failure.

void het_flex_clear(void *obj)

Empty all children in the container.

Parameters: obj flex container handle.

bool het_flex_add(void *obj, void *child, int16_t width, int16_t height, uint8_t grow)

Add children and specify dimensions and expansion factors.

Parameters: obj container handle; child object; width/height child size; grow expansion factor.

Return: true for success; false for failure.

bool het_flex_add_pct(void *obj, void *child, uint8_t width_pct, uint8_t height_pct, uint8_t grow)

Add children by percentage size.

Parameters: obj container handle; child child object; width_pct/height_pct percentage size (recommended 0~100); grow expansion factor.

Return: true for success; false for failure.

void het_flex_update(void *obj)

Triggers layout update and recalculates child geometry.

Parameters: obj container handle.

void het_flex_set_geometry(void *obj, const rect_t rect)

Sets the container geometry area.

Parameters: obj container handle; rect geometry information.

void het_flex_set_padding(void *obj, const het_pad_t padding)

Set container padding.

Parameters: obj container handle; padding padding.

void het_flex_set_gap(void *obj, int16_t gap)

Set the spacing between children.

Parameters: obj container handle; gap spacing pixel value.

void het_flex_set_flow(void *obj, het_flex_dir dir, het_flex_justify justify, het_flex_align align)

Set the spindle direction, spindle assignment, and cross-axis alignment.

Parameters: obj container handle; dir direction; justify main axis allocation; align cross-axis alignment.

Usage example

void *flex = het_flex_create(frm);
het_flex_set_geometry(flex, HET_GEOMETRY(160, 120, 220, 72));
het_flex_set_padding(flex, HET_PADDING(6, 8, 8, 6));
het_flex_set_gap(flex, 8);
het_flex_set_flow(flex,
                  HET_FLEX_DIR_ROW,
                  HET_FLEX_JUSTIFY_SPACE_BETWEEN,
                  HET_FLEX_ALIGN_CENTER);

void *btn_ok = het_button_create(frm->page, HET_BG_MODE_SC, 7);
void *btn_cancel = het_button_create(frm->page, HET_BG_MODE_SC, 7);

het_flex_add_pct(flex, btn_ok, 45, 100, 0);
het_flex_add_pct(flex, btn_cancel, 45, 100, 0);
het_flex_update(flex);
