het_grid grid layout container

UI components

include/het_grid.h

include/het_grid.h

Component Description

het_grid is a two-dimensional grid layout container that places children in specified cells through column and row templates, and supports spanning columns/rows.

  • Suitable for regular grid scenarios such as dashboards, menu matrices, and information panels.

  • First define the template (number of columns/number of rows), and then bind the control to the cell coordinates.

  • Unequal-sized areas can be constructed by spanning rows and columns.

API introduction

void *het_grid_create(compo_form_t *frm)

Create a grid container object.

Parameters: frm target form.

Returns: void* container handle, returns NULL on failure.

void het_grid_clear(void *obj)

Clear all children in the grid.

Parameters: obj grid container handle.

bool het_grid_add(void *obj, void *child, uint8_t col, uint8_t row, uint8_t col_span, uint8_t row_span)

Adds children to the specified cell and sets span across columns/rows.

Parameters: obj container handle; child child object; col/row starting column row index; col_span/row_span span.

Return: true for success; false for failure.

bool het_grid_add_cell(void *obj, void *child, uint8_t col, uint8_t row)

Adds children to a single grid cell (span fixed to 1x1).

Parameters: obj container handle; child child object; col/row target column row index.

Return: true for success; false for failure.

void het_grid_update(void *obj)

Triggers a layout update and recalculates all child geometry.

Parameters: obj container handle.

void het_grid_set_geometry(void *obj, const rect_t rect)

Sets the container geometry area.

Parameters: obj container handle; rect geometry information.

void het_grid_set_padding(void *obj, const het_pad_t padding)

Set container padding.

Parameters: obj container handle; padding padding.

void het_grid_set_gap(void *obj, int16_t col_gap, int16_t row_gap)

Set column spacing and row spacing.

Parameters: obj container handle; col_gap column spacing; row_gap row spacing.

void het_grid_set_template(void *obj, uint8_t cols, uint8_t rows)

Set the grid template (number of columns and rows).

Parameters: obj container handle; cols column number; rows row number.

Usage example

void *grid = het_grid_create(frm);
het_grid_set_geometry(grid, HET_GEOMETRY(160, 120, 220, 160));
het_grid_set_padding(grid, HET_PADDING(8, 8, 8, 8));
het_grid_set_gap(grid, 6, 6);
het_grid_set_template(grid, 3, 2);

void *icon = het_image_create(frm, HET_BG_MODE_2D);
void *name = het_label_create(frm, NULL, 32);
void *value = het_label_create(frm, NULL, 16);

het_grid_add(grid, icon, 0, 0, 1, 2);      // 左侧图标跨两行
het_grid_add_cell(grid, name, 1, 0);       // 标题
het_grid_add(grid, value, 1, 1, 2, 1);     // 数值横跨两列

het_grid_update(grid);
