Component Description

het_arc is an LVGL-style arc (dashboard) component. It consists of three layers: background track arc, indicator arc and knob. It supports three growth modes and touch-drag interaction, and is suitable for scenarios such as volume knobs, instrument panels, and power rings.

growth model

Parameters and options

enumeration value

illustrate

HET_ARC_MODE_NORMAL

Grows forward from the starting point of the background arc (default)

HET_ARC_MODE_REVERSE

Reverse growth from the end point of the background arc

HET_ARC_MODE_SYMMETRICAL

Expand from the center point of the background arc to both sides

API introduction

het_arc_create

Create an arc component.

Parameters: the form to which frm belongs; enable_anim whether to enable numerical gradient animation

Returns: void * arc object pointer, returns NULL on failure

het_arc_set_geometry

Sets the geometric region of the arc.

Parameters: obj arc object pointer; rect area (x/y is the center point, it is recommended that the width and height be equal)

het_arc_set_width

Set the arc width (difference between inner and outer radii).

Parameters: obj arc object pointer; width arc width (pixels), default 10

het_arc_set_knob_size

Set the knob diameter, 0 means hide the knob.

Parameters: obj arc object pointer; size diameter (pixels), default 20

het_arc_set_bg_angles

Set the starting and ending angles of the background arc in units of 0.1°. 0° is in the right horizontal direction and increases clockwise.

Parameters: obj arc object pointer; start starting angle (0.1°); end ending angle (0.1°)

Example: 270° dial → start=1350, end=450

het_arc_set_range

Set the value range.

Parameters: obj arc object pointer; min lower limit; max upper limit

het_arc_set_value

Set the current value without triggering the event callback. The value is automatically clamped to the min~max range.

Parameters: obj arc object pointer; value target value

Note: If enable_anim is enabled when creating, the gradient will be smooth, otherwise it will be refreshed instantaneously.

het_arc_set_value_notify

Set the current value and trigger the VALUE_CHANGED event callback.

Parameters: obj arc object pointer; value target value; param event parameter transparently passed to the callback

het_arc_set_mode

Setting indicates arc growth mode.

Parameters: obj arc object pointer; mode HET_ARC_MODE_NORMAL / REVERSE / SYMMETRICAL

het_arc_set_adjustable

Set whether to allow touch drag to adjust the value.

Parameters: obj arc object pointer; adjustable true=dragable (default), false=display only

het_arc_set_anim_time

Set the duration of the numerical gradient animation. If animation is not enabled when creating, this interface will be invalid.

Parameters: obj arc object pointer; ms animation duration (milliseconds), default 300

het_arc_set_color

Set the color of indicator arcs, background tracks, and knobs.

Parameters: obj arc object pointer; indic_color indicates arc color; track_color background track color; knob_color knob color

het_arc_set_slot

Set event callback, VALUE_CHANGED is triggered when touch dragging or set_value_notify.

Parameters: obj arc object pointer; cb callback function; user_data user data

het_arc_set_visible

Sets the visibility of arc.

Parameters: obj arc object pointer; visible whether it is visible

het_arc_get_value

Get the current value.

Parameters: obj arc object pointer

Return: int16_t current value

het_arc_get_min

Get the lower limit of the value.

Parameters: obj arc object pointer

Return: int16_t minimum value

het_arc_get_max

Get the numerical upper limit.

Parameters: obj arc object pointer

Return: int16_t maximum value

Usage example

/* 创建 270° 仪表盘，带动画 */
void *arc = het_arc_create(frm, true);
het_arc_set_geometry(arc, (rect_t){120, 120, 200, 200});
het_arc_set_bg_angles(arc, 1350, 450);   /* 135°~45°，单位 0.1° */
het_arc_set_range(arc, 0, 100);
het_arc_set_width(arc, 12);
het_arc_set_knob_size(arc, 20);
het_arc_set_color(arc, COLOR_BLUE, COLOR_GRAY, COLOR_WHITE);
het_arc_set_slot(arc, my_arc_cb, NULL);

/* 设值并触发回调 */
het_arc_set_value_notify(arc, 75, NULL);

/* 回调中读取当前值 */
void my_arc_cb(void *obj, het_event_t *evt) {
    if (evt->type == HET_EVENT_VALUE_CHANGED) {
        int16_t v = het_arc_get_value(obj);
    }
}
