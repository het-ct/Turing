Component Description

het_switch provides ON/OFF two-state switching interaction, suitable for Boolean switch configurations such as Wi-Fi, Bluetooth, notifications, and energy-saving modes.

Parameters and options

API introduction

void * het_switch_create(compo_form_t *frm)

Create a switch component.

Parameters: frm target form.

Returns: void* switch component handle, returns NULL on failure.

void het_switch_set_geometry(void *obj, const rect_t rect)

Set the position and size (x/y is the center coordinate).

Parameters: obj switch handle; rect geometry information.

void het_switch_set_checked(void *obj, const bool checked)

Set ON/OFF state (with sliding animation, no event triggering).

Parameters: obj switch handle; checked target state.

void het_switch_set_checked_notify(void *obj, const bool checked, void *param)

Set the state and trigger the event, and the param is passed transparently to the callback.

Parameters: obj switch handle; checked target state; param callback transparent transmission parameter.

void het_switch_set_knob_size(void *obj, const uint8_t size)

Set the knob diameter.

Parameters: obj switch handle; size knob size.

void het_switch_set_color(void *obj, const het_bg_res_t on_style, const het_bg_res_t off_style, const uint16_t knob_color)

Set ON track, OFF track and knob color.

Parameters: obj switch handle; on_style ON state track style; off_style OFF state track style; knob_color knob color.

void het_switch_set_slot(void *obj, event_cb cb, void *user_data)

Register callback, event code is HET_EVENT_VALUE_CHANGED.

Parameters: obj switch handle; cb callback function; user_data user transparent transmission pointer.

void het_switch_set_visible(void *obj, const bool visible)

Set visibility.

Parameters: obj switch handle; visible whether to display.

bool het_switch_get_checked(const void *obj)

Get the current selection status, true means ON.

Parameters: obj switch handle.

Return: bool current switch status.

Usage example

static void on_switch_changed(const het_event_t * const e)
{
    bool on = het_switch_get_checked(e->original);
    (void)on;
}

void *sw = het_switch_create(frm);
het_switch_set_geometry(sw, HET_GEOMETRY(160, 120, 64, 34));
het_switch_set_color(sw,
    HET_BG_COLOR(44, 188, 110),
    HET_BG_COLOR(95, 104, 122),
    COLOR_WHITE);
het_switch_set_checked(sw, true);
het_switch_set_slot(sw, on_switch_changed, NULL);
