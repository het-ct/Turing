set_rotation / set_pivot / set_scale

API introduction

void * het_image_create(compo_form_t *frm, const het_bg_mode mode)

Create a picture component.

Parameters: frm target form; mode resource mode, which determines whether the bottom layer uses a picture control or a rectangular control.

Returns: void* image component handle, returns NULL on failure.

void het_image_set_geometry(void * obj, const rect_t rect)

Set position and size.

Parameters: obj image component handle; rect geometric information.

void het_image_set_pos(void * obj, const int32_t x, const int32_t y)

Set location.

Parameters: obj image component handle; x/y center coordinates.

void het_image_set_size(void * obj, const int32_t w, const int32_t h)

Set size.

Parameters: obj image component handle; w/h width and height.

void het_image_set_src(void * obj, const het_bg_res_t res)

Set resources (image address/RAM data/solid color).

Parameters: obj image component handle; res background resource description.

void het_image_set_rotation(void * obj, const int32_t angle)

Only valid in 2D mode, angle unit is 0.1°.

Parameters: obj image component handle; angle rotation angle, for example, 900 means 90.0°.

void het_image_set_pivot(void * obj, const int32_t x, const int32_t y)

Only valid in 2D mode, set the rotation center.

Parameters: obj image component handle; x/y rotation center coordinates.

void het_image_set_scale(void * obj, const int32_t scale_x, const int32_t scale_y)

For Q8 scaling, the HET_SCALE(f) macro is recommended.

Parameters: obj image component handle; scale_x/scale_y X/Y direction scaling value.

void het_image_set_alpha(void * obj, const uint8_t alpha)

Set transparency.

Parameters: obj image component handle; alpha transparency, usually in the range of 0~255.

void het_image_set_radius(void * obj, const uint8_t radius, const het_radius_pos corner)

Only valid in SC mode, set rectangular rounded corners.

Parameters: obj image component handle; radius corner radius; corner effective corner position.

rect_t het_image_get_geometry(const void * const obj)

Get the current geometry properties.

Parameters: obj image component handle.

Return: rect_t current geometry information.

Usage example

void *img = het_image_create(frm, HET_BG_MODE_2D);
het_image_set_geometry(img, HET_GEOMETRY(160, 120, 80, 80));
het_image_set_src(img, HET_BG_IMG(UI_BUF_LOGO_BIN));
het_image_set_rotation(img, 900);
het_image_set_scale(img, HET_SCALE(0.8f), HET_SCALE(0.8f));
