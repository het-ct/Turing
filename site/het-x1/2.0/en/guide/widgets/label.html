het_label text label component

UI components

Structure diagram

life cycle

Event interception and filtering

het_label does not register object event callbacks and does not actively intercept or consume MSG_CTP_* messages.

Alignment and padding

The padding parameter type of het_label_set_align is het_pad_t, and the field order is {top, left, right, bottom}.

Complete example

API introduction

void * het_label_create(compo_form_t *frm, widget_page_t *page, const u16 max_word_cnt)

Create labels. When page passes NULL, it will automatically go to frm->page_body.

Parameters: frm target form; page specifies the mounting page, and when it is NULL, the default page is used; max_word_cnt text cache capacity.

Returns: void* label handle, returns NULL on failure.

void het_label_set_geometry(void *obj, const rect_t geometry)

Set position and size.

Parameters: obj label handle; geometry geometry information.

void het_label_set_pos(void *obj, int16_t x, int16_t y)

Only set location.

Parameters: obj label handle; x/y center coordinates.

void het_label_set_size(void *obj, int16_t width, int16_t height)

Just set the size.

Parameters: obj label handle; width/height width and height.

void het_label_set_text(void *obj, const char *text)

Set text content (UTF-8).

Parameters: obj label handle; text text content.

void het_label_set_text_fmt(void *obj, const char *fmt, …)

Formatting text, internal buffer maximum 256 bytes.

Parameters: obj label handle; fmt formatting template; variable parameters are expanded according to the template.

void het_label_set_align(void *obj, const uint8_t align, const het_pad_t padding)

Set alignment and padding.

Parameters: obj label handle; align alignment; padding padding.

void het_label_set_font(void *obj, const uint32_t font)

Set font. It is recommended to set the font first and then the text.

Parameters: obj label handle; font font resource ID.

void het_label_set_autosize(void *obj, const bool autosize)

Set whether to automatically size.

Parameters: obj label handle; autosize whether to automatically adjust the size according to the text.

void het_label_set_color(void *obj, const u16 color)

Set text color (RGB565).

Parameters: obj label handle; color text color.

void het_label_set_alpha(void *obj, const u8 alpha)

Set transparency.

Parameters: obj label handle; alpha transparency, usually in the range of 0~255.

void het_label_set_visible(void *obj, const bool visible)

Set visibility.

Parameters: obj label handle; visible whether to display.

Usage example

typedef struct {
    int8_t top;
    int8_t left;
    int8_t right;
    int8_t bottom;
} het_pad_t;

void *label = het_label_create(frm, NULL, 64);
het_label_set_geometry(label, HET_GEOMETRY(160, 60, 120, 24));
het_label_set_font(label, UI_BUF_COFFEE_FONT_ARIAL_11_BIN);
het_label_set_color(label, COLOR_WHITE);
het_label_set_align(label, HET_TEXT_ALIGN_CENTER, HET_PADDING(0, 0, 0, 0));
het_label_set_text_fmt(label, "电量: %d%%", 87);
