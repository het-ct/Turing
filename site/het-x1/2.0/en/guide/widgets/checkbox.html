Component Description

het_checkbox is an LVGL-style checkbox component that adopts a two-layer structure: the outer main background box presents the border color, and the inner sub-background reflects the selected state (solid color or picture). The text is automatically arranged to the right of the checkbox.

Parameters and options

enumeration value

Create parameters

HET_BG_MODE_SC

mode

Solid color filling, supports selected gradient animation, style configured through HET_BG_COLOR

HET_BG_MODE_2D

mode

Picture (such as a tick icon), the selected state switches instantaneously, and the style is configured through HET_BG_IMG

API introduction

het_checkbox_create

Create a checkbox component with a two-layer structure, and the internal sub-background mode is specified by mode.

Parameters: the form to which frm belongs; mode HET_BG_MODE_SC (solid color) or HET_BG_MODE_2D (picture)

Returns: void * checkbox object pointer, returns NULL on failure

het_checkbox_set_pos

Set the position of the checkbox, and the text will be automatically arranged on the right side of the checkbox.

Parameters: obj checkbox object pointer; x X coordinate of the center of the check box; y Y coordinate of the center of the check box

het_checkbox_set_geometry

Set the position and size at the same time to quickly complete the checkbox geometric layout.

Parameters: obj checkbox object pointer; rect geometric information, usually HET_GEOMETRY(x, y, w, h).

het_checkbox_set_box_size

Set the side length and border width of the check box (main background box).

Parameters: obj checkbox object pointer; size outer frame side length (pixels), default 16; border border width (pixels), 0 means the inner layer covers the outer frame

het_checkbox_set_border_color

Set the color of the main background box (border).

Parameters: obj checkbox object pointer; color border color (uint16_t RGB565)

het_checkbox_set_pad

Set the spacing between the checkbox and text.

Parameters: obj checkbox object pointer; pad spacing (pixels), default 8

het_checkbox_set_font

Set the font resource of checkbox and must be called before set_text.

Parameters: obj checkbox object pointer; font font resource address

het_checkbox_set_text

Set the text content of the checkbox.

Parameters: obj checkbox object pointer; text text content

Note: set_font needs to be called first, otherwise the text may be cleared.

het_checkbox_set_text_color

Set text color.

Parameters: obj checkbox object pointer; color text color (uint16_t RGB565)

het_checkbox_set_style

Set the style resources of the selected and unselected states.

Parameters: obj checkbox object pointer; on_style selected style (HET_BG_COLOR or HET_BG_IMG); off_style unselected style

het_checkbox_set_radius

Sets the checkbox’s corner radius.

Parameters: obj checkbox object pointer; radius corner radius (pixels)

het_checkbox_set_anim_time

Set the style gradient animation duration, only effective for solid color mode (HET_BG_MODE_SC).

Parameters: obj checkbox object pointer; ms animation duration (milliseconds), 0 means turning off instantaneous animation switching, default 200

het_checkbox_set_checked

Set the check status and do not trigger event callbacks.

Parameters: obj checkbox object pointer; checked checked state

het_checkbox_set_checked_notify

Set the check status and trigger the VALUE_CHANGED event callback.

Parameters: obj checkbox object pointer; checked checked status; param event parameters transparently passed to the callback

het_checkbox_set_slot

Set event callback, trigger VALUE_CHANGED when touch click or set_checked_notify.

Parameters: obj checkbox object pointer; cb callback function; user_data user data

het_checkbox_set_visible

Set the visibility of the checkbox.

Parameters: obj checkbox object pointer; visible whether it is visible

het_checkbox_get_checked

Get the current check status.

Parameters: obj checkbox object pointer

Return: bool true=selected / false=unselected

Usage example

/* 纯色模式复选框，带渐变动画 */
void *cb = het_checkbox_create(frm, HET_BG_MODE_SC);
het_checkbox_set_pos(cb, 60, 120);
het_checkbox_set_box_size(cb, 20, 2);
het_checkbox_set_border_color(cb, COLOR_GRAY);
het_checkbox_set_radius(cb, 4);
het_checkbox_set_style(cb,
    (het_bg_res_t)HET_BG_COLOR(COLOR_BLUE),   /* 选中：蓝色填充 */
    (het_bg_res_t)HET_BG_COLOR(COLOR_BLACK));  /* 未选中：黑色填充 */
het_checkbox_set_anim_time(cb, 200);
het_checkbox_set_font(cb, (uint32_t)&my_font_16);
het_checkbox_set_text(cb, "同意用户协议");
het_checkbox_set_text_color(cb, COLOR_WHITE);
het_checkbox_set_pad(cb, 8);
het_checkbox_set_slot(cb, my_cb_handler, NULL);

/* 回调中读取状态 */
void my_cb_handler(void *obj, het_event_t *evt) {
    if (evt->type == HET_EVENT_VALUE_CHANGED) {
        bool checked = het_checkbox_get_checked(obj);
    }
}
