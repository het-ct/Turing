UART asynchronous serial port (het_uart.h)

Source file: platform/hal/api/het_uart.h

Overview

Het-X1’s UART0/1 supports universal asynchronous communication, flexible GPIO mapping and Key Match; the chip also provides high-speed HSUART with CTS/RTS, DMA and circular buffering capabilities.

usage

The instance, pins, and baud rate are set by board configuration. Call the read-write interface after initialization; register the callback first for asynchronous reception, cancel the callback and deinitialize before closing the serial port.

Typical process

  1. Get the default configuration or prepare board-level configuration.

  2. Initialize the peripheral and check the return value.

  3. Perform read, write, control, or callback registration operations.

  4. Stop the asynchronous source and deinitialize the peripheral.

Example

#include "het_uart.h"

int uart_send(het_uart_id_t id, const uint8_t *data, uint16_t len)
{
    het_uart_handle_t uart = het_uart_def_cfg();
    int ret = het_uart_init(&uart);
    if (ret != HET_OK) return ret;
    ret = het_uart_write(id, data, len);
    het_uart_deinit(id);
    return ret;
}
