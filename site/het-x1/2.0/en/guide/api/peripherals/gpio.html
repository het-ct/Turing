GPIO general input and output (het_gpio.h)

Source file: platform/hal/api/het_gpio.h

Overview

Het-X1 provides multiple sets of GPIOs including PA, PB, PE, PF, and PG, supporting input and output, pull-up and pull-down, drive capabilities, digital/analog switching, multiplexing mapping, and edge interrupts and wake-up.

usage

GPIO pins and modes are provided by board level configuration. After the application obtains the default handle and initializes it, it can read and write levels or register interrupt callbacks; before releasing, it must first close interrupts and log out callbacks.

Typical process

  1. Get the default configuration or prepare board-level configuration.

  2. Initialize the peripheral and check the return value.

  3. Perform read, write, control, or callback registration operations.

  4. Stop the asynchronous source and deinitialize the peripheral.

Example

#include "het_gpio.h"

int gpio_prepare(void)
{
    het_gpio_handle_t gpio = het_gpio_def_cfg();
    return het_gpio_init(&gpio);
}

int gpio_set_level(het_gpio_id_t pin, uint8_t level)
{
    return het_gpio_write(pin, level);
}

int : 状态码

int het_gpio_register_cb(het_gpio_id_t pin, het_gpio_cb_t cb, void *user_ctx)

注册 GPIO 中断事件回调，触发方式来自板级配置 het_board_config.h

Note

若板级配置中 irq_trigger 为 HET_GPIO_IRQ_NONE，则返回 HET_ERR_GPIO_IRQ_UNSUPPORTED

Parameters:

  • pin – [in] : GPIO pin id

  • cb – [in] : 回调函数指针

  • user_ctx – [in] : 用户上下文，回调时原样传回

Return values:

  • 0 – : 操作成功

  • HET_ERR_GPIO_INVALID_ID – : 无效引脚ID

  • HET_ERR_COMMON_NULL_PTR – : 回调函数指针为空

  • HET_ERR_GPIO_IRQ_UNSUPPORTED – : 该引脚不支持中断或未配置中断触发

  • HET_ERR_GPIO_CALLBACK_EXISTS – : 回调已注册

  • HET_ERR_GPIO_INIT_FAIL – : 回调表已满

Returns:

int : 状态码
