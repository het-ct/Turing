Timer, PWM and QDEC Examples

  • example_hw_timer.c: Period timer, dynamic modification period and count value reading.

  • example_pwm.c: TMR3 CH0 PE12 outputs 1 kHz, 50% duty cycle PWM.

  • example_qdec.c: Incremental encoder count and direction verification.

het_pwm_handle_t pwm = het_pwm_def_cfg();
pwm.id = HET_PWM_TMR3_CH0_PE12;
pwm.freq_hz = 1000;
int ret = het_pwm_init(&pwm);
if (ret < 0) return ret;
return het_pwm_set_duty(pwm.id, 500);

Timer callbacks run in interrupt context. API see Timer timer (het_timer.h)、 PWM pulse width modulation (het_pwm.h) and QDEC Quadrature Decoder (het_qdec.h)。
