UI controls

Overview

The Het-X1 UI components are located at platform/middlewares/gui/components, and the product pages and menus are located at platform/services/UI/form. Control documentation includes creation, layout, style, event and destruction processes.

Control directory

Label, Button, Slider, Bar, Arc, Image, Checkbox, Switch, Roller, Textarea, Flex and Grid all have pages. For the entrance, see UI components。The content of the page is directly organized based on the creation, parameters, events and examples of the corresponding controls in platform/docs/pages/gui/*.js；Instruction planning controls such as RadioBox, Video, and QR codes still lack stable implementation of complete pages, to be developed。

How to use

After creating the parent object, initialize the control, set the size and style, register the event callback, and then add it to the page life cycle. When the page exits, first stop the animation and timer, and then destroy the child objects and resources.

Example

het_button_t *button = het_button_create(parent);
het_button_set_text(button, "Start");
het_button_set_event_cb(button, on_start_clicked, NULL);

/* 页面销毁前停止回调来源，再释放对象。 */
het_button_destroy(button);

Things to note

  • Event callbacks must not block the refresh task for a long time.

  • Image and font resources should verify address, size and life cycle.

  • Control size, touch coordinates, and screen rotation must be configured simultaneously.

Main API

Control API see UI API；For the parameters, return values, event filtering and code examples of each control, please see the corresponding pages under UI components。
