GUI design tools

Current GUI development is based on code, resource files, config.h and platform/middlewares/gui. You can use VS Code to edit pages and controls, and verify components with projects/*/functions/demos.

Pixso’s automatic image cutting, one-click resolution adaptation, visual page editing, CBB event binding, resource consistency check and stable plug-in release package have not yet formed a complete workflow in the current warehouse and are to be developed. Before this, the generated resources must record the original design draft, pixel format, compression method, target address and version.
