Hardware resource description

Het-X1 main resources

resource

ability

Use boundaries

SRAM/PSRAM

On-chip SRAM totals 768 KB, supports external SPI PSRAM

QFN68 on-chip PSRAM configuration is subject to the specific part number

Flash/ROM

Support external SPI NAND, SD NAND

The QFN32 on-chip ROM configuration is subject to the specific part number.

Timer

3-way 32-bit basic timers, 3-way multi-function timers, RTC, WDT

Examples and reuse are subject to the header file.

LCD

8080、QSPI/DSPI/SPI、RGB565

8080/RGB and other interfaces are limited by packaging

Camera

SPI-CSI、DVP

DVP is only available in some packages

Audio

Dual DAC, dual MIC ADC

Analog performance relies on front-end and PCB

UART

Normal UART vs. HSUART up to 2 Mbps

Flow control and pin groups need to check the multiplexing table

SPI/IIC

Two controllers each

Displays and sensors may share reused resources

QDEC/ADC

Incremental encoder, 10-bit ADC

Channels and pins are subject to package

USB/IR/1-Wire

Host/Device, infrared transceiver, single line lighting effect

Protocol stack capabilities need to be confirmed in conjunction with the target project

For driver and API entry, see API reference。Some protocols, algorithms or devices listed in the manual belong to solution capabilities. If the warehouse does not have a corresponding stable implementation, the document will be treated as “to be developed”。
