IMU 运动算法
============

.. container:: module-summary cbb-summary

   **CBB 能力组件**

   对应欧拉角姿态解算与加速度曲线特征学习识别算法。

概述
----

本模块面向 **IMU 姿态与运动算法**。该页面建议补充 IMU 数据输入格式、姿态解算流程、校准方式与动作识别模型。

核心能力
--------

.. container:: capability-list

   * **姿态解算**：说明欧拉角、姿态融合、滤波和校准方法。
   * **动作识别**：说明加速度曲线特征学习、样本训练与推理链路。
   * **数据约束**：说明采样率、安装方向和漂移修正策略。

使用方法
--------

初始化传感器并完成零偏校准，按稳定周期采集加速度和角速度，再送入姿态或运动识别算法。

#. 准备依赖的 HAL、板级资源和任务/中断上下文。
#. 创建配置并注册状态、数据或错误回调。
#. 启动组件，将输入数据或系统事件送入处理接口。
#. 在业务循环中消费输出，并处理超时、断连和资源不足。
#. 停止数据源，等待异步操作结束，再释放组件资源。

API 说明
--------

当前 CBB 页面尚未关联稳定的公开头文件。建议由具体实现提供以下适配层职责，并在公开头文件落地后改为 Doxygen 自动接口说明。

.. list-table:: 建议适配层接口
   :header-rows: 1
   :widths: 28 45 27

   * - 接口职责
     - 说明
     - 调用约束
   * - ``init(config, callback)``
     - 校验配置、创建上下文并注册事件回调。
     - 每个实例只初始化一次。
   * - ``start()``
     - 启动数据源、协议状态机或算法任务。
     - 必须在初始化成功后调用。
   * - ``process(input)``
     - 输入数据帧或系统事件并产生结果。
     - 明确线程、中断和缓冲区所有权。
   * - ``set_callback(callback)``
     - 注册状态、数据和错误通知。
     - 回调中避免阻塞操作。
   * - ``stop() / deinit()``
     - 停止异步来源并释放资源。
     - 先停止，再销毁上下文。

注意事项
--------

* 对实时数据链路明确采样周期、最大延迟和缓冲深度。
* 错误码应保留底层原因，并由产品层决定重试、降级或复位策略。
* 回调、DMA 和任务仍在运行时，不得释放配置、缓冲区或用户上下文。
* CBB 与 HAL 的依赖关系应集中在适配层，避免业务代码直接访问芯片实现。
