内存与存储管理
================

资源概览
--------

根据《图灵平台使用说明书》1.2.3，Het-X1 的片上资源如下：

.. list-table:: Het-X1 内存与存储容量
   :header-rows: 1

   * - 资源
     - 容量/配置
     - 用途
   * - 片上 SRAM
     - 768 KB（CPU 独占 288 KB，NPU 独占 480 KB）
     - 任务栈、堆、DMA 缓冲和实时数据
   * - 片上 PSRAM
     - QFN68 集成 4 MB
     - UI 帧缓冲、音视频缓存和大块临时数据
   * - 片上 ROM
     - QFN32 集成 4 MB
     - 启动代码、固件或只读资源
   * - 外部存储
     - 支持 SPI NAND Flash、SD NAND Flash 和外置 SPI PSRAM
     - 固件、文件系统、模型和产品资源

实际可用容量取决于芯片封装、启动保留区、链接脚本和产品分区，量产前必须以目标板的 map 文件为准。

Flash 分区与代码段
-------------------

擦除区域按 4 KB 对齐。常驻 ``.com`` 代码从 Flash 装载到 RAM，适合中断和严格实时路径；按需加载的
``.bank`` 代码驻留在 SPI ROM，首次调用有装载延迟。中断中禁止调用尚未装载的 ``.bank`` 函数；ISR 使用的
字符串也应放入 ``.com`` 区。

.. code-block:: c

   void __attribute__((section(".com_text"))) timer_isr(void)
   {
       /* 仅执行有界的实时操作 */
   }

内存管理方法
------------

1. 在 ``config.h`` 和链接脚本中确定 SRAM、PSRAM、ROM/Flash 分区及对齐边界。
2. 为每个任务估算栈峰值，为 GUI、摄像头、音频和 DMA 预留连续缓冲区。
3. 固件、资源、文件系统和 OTA 分区互不重叠，升级前校验空间和擦除边界。
4. 编译后检查 map 文件和 ``app.dcf``，记录代码、只读数据、堆和栈的使用量。

注意事项
--------

* DMA 缓冲区必须满足对齐、缓存一致性和生命周期要求。
* UI 双缓冲和模型内存优先放入 PSRAM，但要评估带宽和最坏帧耗时。
* ISR、看门狗和低功耗唤醒路径使用常驻 RAM 代码，避免运行时装载。
* 当前工程没有统一的动态内存统计 API；堆水位、泄漏检测和碎片整理工具 **待开发**。
