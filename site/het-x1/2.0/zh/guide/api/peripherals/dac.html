DAC 数模转换（het_dac.h）

源文件：platform/hal/api/het_dac.h

概述

DAC 用于输出可编程模拟电平或连续采样数据，可服务于音频、波形和模拟控制场景。实际通道、精度和输出范围以板级实现为准。

用法

取得默认配置后初始化指定 DAC 实例，通过单点写入或缓冲区写入输出数据，完成后反初始化。

典型流程

  1. 获取默认配置或准备板级配置。

  2. 初始化外设并检查返回值。

  3. 执行读写、控制或回调注册操作。

  4. 停止异步来源并反初始化外设。

示例

#include "het_dac.h"

int dac_write_value(het_dac_id_t id, uint8_t channel, uint32_t value)
{
    het_dac_config_t cfg = het_dac_def_cfg();
    int ret = het_dac_init(id, &cfg);
    if (ret != HET_OK) return ret;
    ret = het_dac_write(id, channel, value);
    het_dac_deinit(id);
    return ret;
}

API 介绍

Functions

het_dac_config_t het_dac_def_cfg(void)

获取 DAC 默认配置。

返回:

默认配置：12 位分辨率、内部参考、轮询模式。

int het_dac_init(het_dac_id_t id, const het_dac_config_t *config)

初始化 DAC 实例。

参数:

  • id -- [in] DAC 实例 ID，例如 HET_DAC_ID_0。

  • config -- [in] DAC 配置参数（分辨率、参考电压、传输模式）。

返回:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_dac_deinit(het_dac_id_t id)

反初始化 DAC 实例。

参数:

  • id -- [in] DAC 实例 ID。

返回:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_dac_write(het_dac_id_t id, uint8_t channel, uint32_t value)

按初始化传输模式输出单通道原始 DAC 值。

备注

DMA 模式下通知 HET_DAC_EVENT_DONE、HET_DAC_EVENT_ERROR。

参数:

  • id -- [in] DAC 实例 ID。

  • channel -- [in] DAC 通道号。

  • value -- [in] 原始输出值。

返回:

ret > 0 成功或已启动；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_dac_write_buffer(het_dac_id_t id, uint8_t channel, const uint16_t *data, uint16_t len)

按初始化传输模式输出波形缓冲区。

备注

DMA 模式下通知 HET_DAC_EVENT_DONE、HET_DAC_EVENT_ERROR。

参数:

  • id -- [in] DAC 实例 ID。

  • channel -- [in] DAC 通道号。

  • data -- [in] 波形数据缓冲区。

  • len -- [in] 数据长度。

返回:

ret > 0 成功或已启动；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_dac_register_cb(het_dac_id_t id, het_dac_cb_t cb, void *user_ctx)

注册 DAC 事件回调。

参数:

  • id -- [in] DAC 实例 ID。

  • cb -- [in] 回调函数。

  • user_ctx -- [in] 用户上下文。

返回:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_dac_unregister_cb(het_dac_id_t id)

注销 DAC 事件回调。

参数:

  • id -- [in] DAC 实例 ID。

返回:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。
