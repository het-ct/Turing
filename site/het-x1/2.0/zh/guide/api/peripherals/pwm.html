PWM 脉宽调制（het_pwm.h）

源文件：platform/hal/api/het_pwm.h

概述

Het-X1 的 Timer3/4 支持双通道 PWM，Timer5 最多支持 6 路 PWM，可用于背光、蜂鸣器、电机和灯效控制。

用法

由板级配置选择定时器通道和引脚。初始化后设置频率与千分比占空比，再启动输出；修改参数时检查返回值。

典型流程

  1. 获取默认配置或准备板级配置。

  2. 初始化外设并检查返回值。

  3. 执行读写、控制或回调注册操作。

  4. 停止异步来源并反初始化外设。

示例

#include "het_pwm.h"

int pwm_start_output(het_pwm_id_t id, uint32_t hz, uint32_t duty_permile)
{
    het_pwm_handle_t pwm = het_pwm_def_cfg();
    int ret = het_pwm_init(&pwm);
    if (ret != HET_OK) return ret;
    if ((ret = het_pwm_set_frequency(id, hz)) != HET_OK) return ret;
    if ((ret = het_pwm_set_duty(id, duty_permile)) != HET_OK) return ret;
    return het_pwm_start(id);
}

返回:

int : 状态码

int het_pwm_deinit(het_pwm_id_t pwm_id)

pwm 复位

参数:

  • pwm_id -- [in] : pwm ID号

返回值:

  • HET_OK -- : 操作成功

  • 其他 -- : 操作失败

返回:

int : 状态码

int het_pwm_start(het_pwm_id_t pwm_id)

pwm 通道控制 (通道号由 pwm_id 内部编码)

参数:

  • pwm_id -- [in] : pwm 引脚 ID (含定时器+通道号)

返回值:

  • HET_OK -- : 操作成功

  • 其他 -- : 操作失败

返回:

int : 状态码

int het_pwm_stop(het_pwm_id_t pwm_id)

pwm 停止

参数:

  • pwm_id

返回值:

  • HET_OK -- : 操作成功

  • 其他 -- : 操作失败

返回:

int : 状态码

int het_pwm_set_duty(het_pwm_id_t pwm_id, uint32_t duty_permile)

设置 pwm 占空比 (通道号由 pwm_id 内部编码)

参数:

  • pwm_id -- [in] : pwm 引脚 ID (含定时器+通道号)

  • duty_permile -- [in] : 占空比值 (千分比, 0~1000)

返回值:

  • HET_OK -- : 操作成功

  • 其他 -- : 操作失败

返回:

int : 状态码

int het_pwm_get_duty(het_pwm_id_t pwm_id, uint32_t *p_duty_permile)

int

返回:

int : 状态码
