Timer 定时器（het_timer.h）

源文件：platform/hal/api/het_timer.h

概述

Het-X1 提供 6 个 32 位定时器。Timer0~2 支持定时/计数，Timer3~5 还支持捕获和 PWM，并提供多种时钟源与预分频。

用法

选择定时器实例，设置周期并按需注册回调。启动后可读取计数或动态调整周期；停止定时器后再注销回调和反初始化。

典型流程

  1. 获取默认配置或准备板级配置。

  2. 初始化外设并检查返回值。

  3. 执行读写、控制或回调注册操作。

  4. 停止异步来源并反初始化外设。

示例

#include "het_timer.h"

int timer_start_periodic(het_timer_id_t id, uint32_t period_us)
{
    het_timer_config_t cfg = het_timer_def_cfg();
    int ret = het_timer_init(id, &cfg);
    if (ret != HET_OK) return ret;
    if ((ret = het_timer_set_period(id, period_us)) != HET_OK) return ret;
    return het_timer_start(id);
}

API 介绍

Functions

het_timer_config_t het_timer_def_cfg(void)

获取定时器默认配置。

返回:

默认配置：周期模式、1000us 周期。

int het_timer_init(het_timer_id_t id, const het_timer_config_t *config)

使用配置参数初始化定时器。

备注

周期或单次模式下可通知定时器事件。

参数:

  • id -- [in] TIMER 实例 id，例如 HET_TIMER_ID_0。

  • config -- [in] 周期、定时器模式。

返回:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_timer_deinit(het_timer_id_t id)

反初始化定时器。

参数:

  • id -- [in] TIMER 实例 id。

返回:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_timer_start(het_timer_id_t id)

启动定时器。

备注

触发 HET_TIMER_EVENT_PERIOD 或 HET_TIMER_EVENT_ONESHOT。

参数:

  • id -- [in] TIMER 实例 id。

返回:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_timer_stop(het_timer_id_t id)

停止定时器。

参数:

  • id -- [in] TIMER 实例 id。

返回:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_timer_set_period(het_timer_id_t id, uint32_t period_us)

设置定时器周期，用于运行中调节的场景。

参数:

  • id -- [in] TIMER 实例 id。

  • period_us -- [in] 周期，单位 us。

返回:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_timer_get_count(het_timer_id_t id, uint32_t *count)

获取当前计数值。

参数:

  • id -- [in] TIMER 实例 id。

  • count -- [out] 计数值输出指针。

返回:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_timer_register_cb(het_timer_id_t id, het_timer_cb_t cb, void *user_ctx)

注册定时器事件回调。

备注

见 TIMER 事件。

参数:

  • id -- [in] TIMER 实例 id。

  • cb -- [in] 回调函数。

  • user_ctx -- [in] 用户上下文。

返回:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。

int het_timer_unregister_cb(het_timer_id_t id)

注销定时器事件回调。

参数:

  • id -- [in] TIMER 实例 id。

返回:

ret > 0 成功；ret == 0 失败；ret < 0 为 het_err_t 错误码。
