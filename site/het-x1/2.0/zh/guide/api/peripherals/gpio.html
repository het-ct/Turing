GPIO 通用输入输出（het_gpio.h）

源文件：platform/hal/api/het_gpio.h

概述

Het-X1 提供 PA、PB、PE、PF、PG 多组 GPIO，支持输入输出、上下拉、驱动能力、数字/模拟切换、复用映射以及边沿中断和唤醒。

用法

GPIO 引脚和模式由板级配置提供。应用获取默认句柄并初始化后，可读写电平或注册中断回调；释放前先关闭中断并注销回调。

典型流程

  1. 获取默认配置或准备板级配置。

  2. 初始化外设并检查返回值。

  3. 执行读写、控制或回调注册操作。

  4. 停止异步来源并反初始化外设。

示例

#include "het_gpio.h"

int gpio_prepare(void)
{
    het_gpio_handle_t gpio = het_gpio_def_cfg();
    return het_gpio_init(&gpio);
}

int gpio_set_level(het_gpio_id_t pin, uint8_t level)
{
    return het_gpio_write(pin, level);
}

API 介绍

Functions

int het_gpio_init(het_gpio_handle_t *p_gpio)

gpio 配置

参数:

  • p_gpio -- [in] : gpio 配置句柄

返回值:

  • 0 -- : 操作成功

  • HET_ERR_COMMON_NULL_PTR -- : 句柄为空

  • HET_ERR_GPIO_INVALID_ID -- : 无效引脚ID

  • HET_ERR_GPIO_INVALID_CHIP_PIN -- : 芯片引脚无效

  • HET_ERR_GPIO_INVALID_MODE -- : 无效GPIO模式

  • HET_ERR_GPIO_INIT_FAIL -- : 初始化失败

返回:

int : 状态码

int het_gpio_deinit(het_gpio_id_t pin)

反初始化 GPIO，恢复为高阻态

参数:

  • pin -- [in] : GPIO pin id

返回值:

  • 0 -- : 操作成功

  • HET_ERR_GPIO_INVALID_ID -- : 无效引脚ID

  • HET_ERR_GPIO_INVALID_CHIP_PIN -- : 芯片引脚无效

返回:

int : 状态码

int het_gpio_write(het_gpio_id_t pin, uint8_t level)

设置 GPIO 输出电平

参数:

  • pin -- [in] : GPIO pin id

  • level -- [in] : 输出电平 0-低电平, 1-高电平

返回值:

  • 0 -- : 操作成功

  • HET_ERR_GPIO_INVALID_ID -- : 无效引脚ID

  • HET_ERR_GPIO_INVALID_CHIP_PIN -- : 芯片引脚无效

返回:

int : 状态码

int het_gpio_read(het_gpio_id_t pin, uint8_t *level)

读取 GPIO 输入或输出锁存电平

参数:

  • pin -- [in] : GPIO pin id

  • level -- [out] : 电平输出指针 0-低电平, 1-高电平

返回值:

  • 0 -- : 操作成功

  • HET_ERR_GPIO_INVALID_ID -- : 无效引脚ID

  • HET_ERR_COMMON_NULL_PTR -- : level指针为空

  • HET_ERR_GPIO_INVALID_CHIP_PIN -- : 芯片引脚无效

返回:

int : 状态码

int het_gpio_register_cb(het_gpio_id_t pin, het_gpio_cb_t cb, void *user_ctx)

注册 GPIO 中断事件回调，触发方式来自板级配置 het_board_config.h

备注

若板级配置中 irq_trigger 为 HET_GPIO_IRQ_NONE，则返回 HET_ERR_GPIO_IRQ_UNSUPPORTED

参数:

  • pin -- [in] : GPIO pin id

  • cb -- [in] : 回调函数指针

  • user_ctx -- [in] : 用户上下文，回调时原样传回

返回值:

  • 0 -- : 操作成功

  • HET_ERR_GPIO_INVALID_ID -- : 无效引脚ID

  • HET_ERR_COMMON_NULL_PTR -- : 回调函数指针为空

  • HET_ERR_GPIO_IRQ_UNSUPPORTED -- : 该引脚不支持中断或未配置中断触发

  • HET_ERR_GPIO_CALLBACK_EXISTS -- : 回调已注册

  • HET_ERR_GPIO_INIT_FAIL -- : 回调表已满

返回:

int : 状态码

int het_gpio_unregister_cb(het_gpio_id_t pin)

注销 GPIO 中断事件回调

参数:

  • pin -- [in] : GPIO pin id

返回值:

  • 0 -- : 操作成功

  • HET_ERR_GPIO_INVALID_ID -- : 无效引脚ID

  • HET_ERR_GPIO_CALLBACK_NOT_FOUND -- : 未找到已注册的回调

返回:

int : 状态码

int het_gpio_irq_enable(het_gpio_id_t pin)

使能 GPIO 中断

备注

调用前需先通过 het_gpio_register_cb 注册回调

参数:

  • pin -- [in] : GPIO pin id

返回值:

  • 0 -- : 操作成功

  • HET_ERR_GPIO_INVALID_ID -- : 无效引脚ID

  • HET_ERR_GPIO_CALLBACK_NOT_FOUND -- : 未注册回调，请先调用 het_gpio_register_cb

  • HET_ERR_GPIO_INVALID_CHIP_PIN -- : 芯片引脚无效

返回:

int : 状态码

int het_gpio_irq_disable(het_gpio_id_t pin)

禁用 GPIO 中断

参数:

  • pin -- [in] : GPIO pin id

返回值:

  • 0 -- : 操作成功

  • HET_ERR_GPIO_INVALID_ID -- : 无效引脚ID

返回:

int : 状态码
