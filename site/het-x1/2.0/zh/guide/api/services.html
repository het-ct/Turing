服务 API

本节只介绍 platform/services 中采用 het 前缀的公开服务。服务通常跨越多个 HAL 和 中间件，应由产品应用统一初始化，不应由单个控件在事件回调中隐式启动。

音频播放声明

Functions

int het_audio_init(het_audio_id_t id, const het_audio_config_t *config)

初始化音频播放设备。

备注

DAC 硬件配置必须在首次使用 DAC 前完成。

参数:

  • id -- [in] 音频设备 ID。

  • config -- [in] 初始化配置；传入 NULL 时使用模块默认配置。

返回:

HET_OK 初始化成功；其他值为 het_err_t 错误码。

int het_audio_play(het_audio_id_t id, het_audio_type_t type, uint32_t addr, uint32_t len, het_audio_mode_t mode)

播放 Flash 中的 MP3 或 WAV 音频资源。

参数:

  • id -- [in] 音频设备 ID。

  • type -- [in] 音频资源类型。

  • addr -- [in] 音频资源的 Flash 地址。

  • len -- [in] 音频资源长度，单位为字节。

  • mode -- [in] 阻塞或异步播放模式。

返回:

HET_OK 播放启动成功；其他值为 het_err_t 错误码。

int het_audio_stop(het_audio_id_t id)

停止音频资源播放。

参数:

  • id -- [in] 音频设备 ID。

返回:

HET_OK 停止成功；其他值为 het_err_t 错误码。

int het_audio_process(het_audio_id_t id)

处理异步音频播放任务。

备注

异步播放期间应在主循环中周期调用本接口。

参数:

  • id -- [in] 音频设备 ID。

返回:

HET_OK 处理成功；其他值为 het_err_t 错误码。

int het_audio_is_playing(het_audio_id_t id, bool *playing)

查询音频资源是否正在播放。

参数:

  • id -- [in] 音频设备 ID。

  • playing -- [out] 返回播放状态，true 表示正在播放。

返回:

HET_OK 查询成功；其他值为 het_err_t 错误码。

int het_audio_play_block(het_audio_id_t id, het_audio_type_t type, uint32_t addr, uint32_t len)

阻塞播放 MP3 或 WAV 音频资源。

参数:

  • id -- [in] 音频设备 ID。

  • type -- [in] 音频资源类型。

  • addr -- [in] 音频资源的 Flash 地址。

  • len -- [in] 音频资源长度，单位为字节。

返回:

HET_OK 播放完成；其他值为 het_err_t 错误码。

int het_player_set_volume(het_audio_id_t id, uint8_t volume)

设置音频播放音量。

参数:

  • id -- [in] 音频设备 ID。

  • volume -- [in] 音量，范围 0~100。

返回:

HET_OK 设置成功；其他值为 het_err_t 错误码。
